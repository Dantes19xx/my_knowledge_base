Бинарный поиск - это алгоритм. На входе он получает отсортированный список элеметов. Если искомый элемент присутствует в списке, бинарный поиск возвращает ту позицию, в которой он был найдет, иначе *null*.

С бинарным поиском каждый раз "загадывается" число в середине.

> Для списка из n элементов, бинарный поиск выполняется за log2n шагов, тогда как простой поиск будет выполнен за n шагов.

Логарифм — это **обратная операция к возведению в степень**:
- `2^10 = 1024`
    
- `log₂(1024) = 10`
---
Когда максимальное количество попыток совпадает с длиной списка, такой алгоритм называется *линейным*.
