
Стек вызовов — это структура данных, которая используется для хранения информации о текущих активных подпрограммах в программе. Каждый раз, когда происходит вызов функции или метода, информация о текущем контексте (например, параметры, локальные переменные, точка возврата) добавляется в стек. Когда функция завершает выполнение, информация об этом вызове удаляется из стека, и программа продолжает выполнение с того места, где была остановлена.

## Основные понятия:

1. **Вход в функцию**:
   Когда вызывается функция, она помещается в стек. Этот процесс называется "push" (вставка).
   
2. **Возврат из функции**:
   Когда функция завершает выполнение и возвращает результат, информация о функции удаляется из стека. Этот процесс называется "pop" (удаление).

3. **Порядок выполнения**:
   В стеке вызовов используется принцип LIFO (Last In, First Out) — последним вошедшим является первым, кто выйдет.

4. **Пример стека вызовов**:
   При вызове функций стек будет выглядеть следующим образом:

> Вызов A  
> |  
> |-> Вызов B  
> | |  
> | |-> Вызов C  
> |  
> |-> Вызов D


- Вначале выполняется вызов функции A.
- Затем функция A вызывает функцию B, и она добавляется в стек.
- Функция B вызывает функцию C, и она также попадает в стек.
- После завершения функции C, она удаляется из стека, и выполнение возвращается в функцию B.
- После завершения функции B, она также удаляется, и выполнение возвращается в функцию A.
- После завершения функции A, стек полностью очищается.

## Применения стека вызовов:

- **Отладка**: Стек вызовов помогает отладчикам отслеживать, какие функции были вызваны, и в каком порядке.
- **[[Рекурсия]]**: Стек вызовов важен для рекурсивных функций, так как каждый рекурсивный вызов создает новый слой в стеке.
- **Ошибка Stack Overflow**: Когда стек вызовов переполняется, например, из-за бесконечной рекурсии, возникает ошибка "Stack Overflow".

## Важные характеристики:

- **Размер стека**: Ограничен памятью и может вызвать ошибку переполнения стека, если количество вызовов слишком велико.
- **Доступ к данным стека**: Во время выполнения программы можно получить доступ только к верхним элементам стека (например, текущей функции). Доступ к нижним элементам невозможен до удаления верхних.

## Пример на Python:

```python
def function_a():
 function_b()

def function_b():
 function_c()

def function_c():
 print("End of the stack")

function_a()
```


---
В этом примере, стек вызовов будет выглядеть следующим образом:


```
function_a() -> function_b() -> function_c()
```

Когда `function_c` завершит выполнение, она будет удалена из стека, и выполнение вернется в `function_b`, которая затем завершится, и так далее.
