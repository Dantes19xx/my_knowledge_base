- Это **сопоставление URL → функции**.
    
- В Flask задаётся через `@app.route(...)` или в [[Flask - Blueprint|блюпринтах]].
    

 Пример:
```python
@app.route("/hello")
def hello():
    return "Hello!"
``` 

Здесь `/hello` — это маршрут.

---

## 📌 View (представление)

- Это **функция, которая обрабатывает запрос и возвращает ответ**.
    
- В Django и других MVC-фреймворках используется термин "view" (представление), потому что функция **"представляет" данные пользователю**.
    
- Flask перенял этот термин: view = обработчик HTTP-запроса.
    

---

## 📌 Связь

- Route указывает **какой URL должен вызвать какую view-функцию**.
    
- View — это сам обработчик, который возвращает HTML, JSON или другой ответ.
    

В Flask:
```python
@app.route("/users")
def users_list():   # ← view-функция
    return "List of users"
```

## 📌 Почему путают

- Иногда весь модуль с обработчиками (`routes.py`) называют **views.py**, по традиции из Django.
    
- В Flask чаще используется слово **routes**, но правильнее говорить **view-функции**, потому что именно они формируют ответ.
    

---

👉 Можно думать так:

- **Route** = адрес на карте.
    
- **View** = что пользователь увидит, когда придёт по этому адресу.
