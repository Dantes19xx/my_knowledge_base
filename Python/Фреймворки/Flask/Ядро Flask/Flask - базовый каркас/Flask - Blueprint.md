## Что такое Blueprint

**Blueprint** — это специальный объект во [[Flask — базовый каркас|Flask]], позволяющий организовать маршруты (роуты), обработчики и связанные с ними ресурсы в отдельные модули.  
Он работает как «мини-приложение», которое потом подключается к основному Flask-приложению.

---

## Для чего нужен

- **Структурирование кода**: разносить разные части логики (например, `auth`, `admin`, `api`) по отдельным файлам.
    
- **Повторное использование**: один и тот же Blueprint можно подключить в разные проекты.
    
- **Группировка маршрутов**: можно задавать общий `url_prefix`, чтобы у всех маршрутов был одинаковый префикс.
    
- **Масштабируемость**: удобно, когда приложение растёт и превращается в набор модулей.
    

## Где находится

Blueprint — это класс в библиотеке **`flask`**, подключается так:

```python
from flask import Blueprint
```

## Пример

```python
from flask import Blueprint

auth_bp = Blueprint("auth", __name__)

@auth_bp.route("/login")
def login():
    return "Страница входа"
```


---

`Blueprint` — встроенный элемент **фреймворка Flask**.  
Это не отдельная библиотека и не внешний модуль, а официальная часть архитектуры Flask, упрощающая построение больших приложений.
