## Что это

**MarkupSafe** — небольшая библиотека Python для безопасной работы со строками в HTML/XML.  
Она используется внутри **Jinja2** (а значит, и во Flask) для защиты от XSS-атак.

---

## Основные возможности

- **Экранирование спецсимволов**
    
    - превращает `<`, `>`, `&` в безопасные HTML-сущности (`&lt;`, `&gt;`, `&amp;`)
        
- **Тип `Markup`**
    
    - строковый класс, который «помечает» строку как безопасную для HTML
        
- **Автоматическая защита от XSS**
    
    - в Jinja2 все переменные по умолчанию проходят через MarkupSafe
        
- **Явная вставка HTML**
    
    - если нужно отобразить «сырой» HTML, его можно обернуть в `Markup`
        

---

## Роль во Flask и Jinja2

- Когда в шаблон подставляется переменная `{{ user_input }}`, Jinja2 автоматически применяет MarkupSafe → злоумышленник не сможет внедрить `<script>`.
    
- Если разработчик сознательно хочет вставить HTML, можно использовать фильтр `|safe` (внутри — это MarkupSafe).
    

---

## Особенности

- Очень маленькая и быстрая библиотека
    
- Не шифрует данные, а только экранирует их
    
- Используется почти во всех шаблонизаторах Python
    

---

📌 **Итог**: MarkupSafe — это «щит» против XSS во Flask. Он гарантирует, что данные, подставляемые в шаблоны, не смогут повредить HTML-страницу или запустить вредоносный код.
