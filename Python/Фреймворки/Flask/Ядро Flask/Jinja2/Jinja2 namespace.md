## Что такое namespace
В Jinja переменные, созданные через `{% set %}` **внутри цикла**, не сохраняются наружу.  
Чтобы иметь возможность изменять значение переменной внутри цикла и использовать его после — применяется объект `namespace`.

## Синтаксис
```jinja2
{% set ns = namespace(var='initial') %}

{% for item in items %}
    {% if ns.var == 'initial' %}
        {% set ns.var = item %}
    {% endif %}
{% endfor %}

Результат: {{ ns.var }}
```


## Пример использования

Задача: взять **первое непустое значение** из списка словарей.

```jinja2
{% set ns = namespace(first_value=None) %}
{% for row in rows %}
    {% if not ns.first_value %}
        {% set candidate = row['date'] %}
        {% if candidate is not none %}
            {% set ns.first_value = candidate %}
        {% endif %}
    {% endif %}
{% endfor %}

Первая дата: {{ ns.first_value }}
```


## Ключевые моменты

- `namespace` создаётся один раз:

```jinja2
{% set ns = namespace(myvar=None) %}
```

- Все атрибуты `ns` можно изменять внутри цикла, и изменения **сохраняются наружу**.
    
- Удобно использовать, когда нужно:
    
    - найти первое/последнее значение;
        
    - накапливать результат;
        
    - сохранять счётчики, флаги и т. п.
        

## Практика

- Используй `namespace`, если нужно менять переменную внутри цикла и использовать её после.
    
- Если переменная не должна сохраняться — достаточно обычного `{% set %}`.
