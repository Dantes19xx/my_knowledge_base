#jinja2 #шаблонизатор

## Что такое фильтры
Фильтры в Jinja2 — это функции, которые применяются к значению прямо в шаблоне.  
Синтаксис:  

```jinja2
{{ variable | filter_name }}
{{ variable | filter_name(arg1, arg2) }}
```

Фильтры можно **цеплять** через `|` (pipe), передавая результат одного в другой.

## Встроенные фильтры

### Работа со строками

- `lower` — привести к нижнему регистру

```jinja2
{{ "Hello" | lower }} → "hello"
```

- `upper` — привести к верхнему регистру
    
- `capitalize` — первая буква заглавная
    
- `replace("a", "b")` — заменить подстроку
    
- `trim` — убрать пробелы с краёв


---

### Работа с коллекциями

- `length` — длина списка/строки

```jinja2
{{ [1,2,3] | length }} → 3
```

- `join(", ")` — объединить список строк
    
- `sort` — отсортировать
    
- `unique` — оставить только уникальные


---

### Работа с числами

- `round(2)` — округлить до 2 знаков
    
- `int` — привести к целому
    

### Работа с датами

Jinja2 сам по себе не форматирует даты, но можно подключать фильтры.  
Пример часто используемого — `date`:

```jinja2
{{ mydate | date("%Y-%m-%d") }}
```


---

## [[Пользовательские фильтры в Jinja2]]

Можно определять свои фильтры в Python и подключать их в Jinja:

```python
def date_or_none(value):
    if value is None:
        return "-"
    return value.strftime("%Y-%m-%d")

env.filters["date_or_none"] = date_or_none
```

Использование в шаблоне:

```jinja2
{{ user.birth_date | date_or_none }}
```

→ выведет дату в формате `2025-08-15`, а если `None` — прочерк `-`.


---

## Цепочки фильтров

Фильтры можно комбинировать:

```jinja2
{{ "   Hello  " | trim | lower }}
→ "hello"
```


---

## Практика

- Используй фильтры, чтобы упрощать шаблоны (минимум логики в HTML).
    
- Делай свои фильтры для бизнес-логики (например, `date_or_none`, `safe_name`, `as_currency`).
    
- Помни: фильтры возвращают **новое значение**, оригинальная переменная не изменяется.
