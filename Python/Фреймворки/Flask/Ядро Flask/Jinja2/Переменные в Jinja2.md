# Переменные в Jinja2

## Основы
В Jinja2 переменные берутся из контекста (например, переданного во Flask через `render_template`).  
Они вставляются в шаблон с помощью двойных фигурных скобок:

```jinja2
{{ user.name }}
{{ 3 + 4 }}
```


---

## Работа с атрибутами и индексами

- Доступ к атрибутам объекта:

```jinja2
{{ user.username }}
```

- Доступ по индексу:
```jinja2
{{ items[0] }}
{{ dict["key"] }}
```

---
## Операции с переменными

Можно использовать арифметику и конкатенацию:

```jinja2
{{ price * quantity }}
{{ "Hello " + user.name }}
```


---

## [[Jinja2 Фильтры|Фильтры]]

Переменные можно преобразовывать через фильтры (`|`):

```jinja2
{{ name | upper }}
{{ items | length }}
{{ date | date_or_none }}
```


---

## Проверка существования

Чтобы не упасть на неопределённой переменной:

```jinja2
{% if user is defined %}
    {{ user.name }}
{% endif %}
```


---

## Значение по умолчанию

Используется фильтр `default`:

```jinja2
{{ user.nickname | default("Anon") }}
```


---

## Циклы с переменными

Внутри [[Циклы в Jinja2|for]] доступны переменные цикла:

```jinja2
{% for item in items %}
  {{ loop.index }}: {{ item }}
{% endfor %}
```


---

Доступные переменные:

- `loop.index` — номер итерации (начиная с 1).
    
- `loop.index0` — номер итерации (с 0).
    
- `loop.first` — `True`, если первая итерация.
    
- `loop.last` — `True`, если последняя итерация.
    

---

## [[Jinja2 namespace|Namespace]] для изменения переменных

Для сохранения значений внутри циклов:

```jinja2
{% set ns = namespace(found=false) %}
{% for item in items %}
    {% if item == "target" %}
        {% set ns.found = true %}
    {% endif %}
{% endfor %}
{{ ns.found }}
```


---

# Резюме

- Переменные берутся из контекста и выводятся через `{{ ... }}`.
    
- Можно работать с атрибутами, индексами, фильтрами и тестами.
    
- Для сложной логики — использовать `namespace`, условия и циклы.
