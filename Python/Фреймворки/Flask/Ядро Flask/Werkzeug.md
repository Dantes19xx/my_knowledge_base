## Что это

**Werkzeug** — это WSGI-библиотека на Python, на которой построен [[Flask — базовый каркас|Flask]].  
Название переводится с немецкого как _«инструмент»_. Она обеспечивает низкоуровневые механизмы для работы с HTTP и WSGI.

📌 Flask = «тонкий слой» над Werkzeug + [[Что такое Jinja2|Jinja2]].

---

## Основные возможности

- **WSGI-утилиты**
    
    - запуск дев-сервера
        
    - поддержка middleware
        
    - работа как с серверной, так и с клиентской частью [[WSGI]]
        
- **Маршрутизация (routing)**
    
    - сопоставление URL с функцией
        
    - динамические параметры в маршрутах
        
    - поддержка конверторов типов (`int`, `string`, `path` и т.д.)
        
- **Обработка HTTP-запросов и ответов**
    
    - класс `Request` для удобного доступа к данным запроса (метод, заголовки, тело)
        
    - класс `Response` для формирования ответа
        
    - cookies, заголовки, редиректы
        
- **Отладка**
    
    - интерактивный отладочный web-консоль (debugger)
        
    - полезна при разработке Flask-приложений
        
- **Безопасность**
    
    - работа с cookies
        
    - защита от подделки заголовков
        
    - безопасное управление сессиями (совместно с [[ItsDangerous]])
        

---

## Роль в Flask

- Flask **не реализует сам маршрутизацию и WSGI**, он делегирует это Werkzeug.
    
- Все объекты вроде `request`, `response`, `url_map` — это обёртки вокруг классов из Werkzeug.
    
- Когда ты пишешь:

```python
from flask import request
```

- на деле это `werkzeug.wrappers.Request`.
    

---

## Особенности

- Независим от Flask — можно использовать отдельно для своих WSGI-приложений.
    
- Гибкий: можно писать собственные маршрутизаторы, middleware и даже мини-фреймворки.
    
- Хорошо интегрируется с другими библиотеками Python.
    

---

📌 **Итог**: Werkzeug — это фундамент Flask, обеспечивающий WSGI, маршрутизацию и удобные HTTP-утилиты. Flask — это, по сути, «надстройка» над Werkzeug с добавлением синтаксического сахара и интеграцией с Jinja2.
