## Что это

**Flask-SocketIO** — расширение Flask, добавляющее поддержку **WebSocket** и протокола **Socket.IO**.  
Позволяет создавать **реактивные (real-time)** приложения: чат, уведомления, live-стримы.

---

## Основные возможности

- **Поддержка WebSocket** (через Socket.IO)
    
- **Двунаправленная связь** клиент ↔ сервер
    
- **Асинхронность**: совместимо с `eventlet`, `gevent`, `asyncio`
    
- **Комнаты (rooms)**: группировка клиентов для общения
    
- **Broadcast**: рассылка сообщений всем подключённым пользователям
    
- **Поддержка fallback**: если WebSocket недоступен → переключение на long polling
    
- **Интеграция с Flask**: использование `request`, `session`, декораторов
    

---

## Роль во Flask

- Расширяет Flask для работы в **реальном времени**
    
- Даёт API, похожее на стандартные роуты Flask, но для событий
    
- Используется для чатов, уведомлений, мониторинговых панелей, игр
    

---

## Типичный рабочий процесс

1. Инициализация:
```python
from flask_socketio import SocketIO

socketio = SocketIO(app)
```

2. Обработка событий:
```python
@socketio.on("message")
def handle_message(msg):
    print("Получено сообщение:", msg)
```

3. Отправка сообщений:
```python
socketio.emit("message", {"data": "Привет, клиент!"})
```

4. Запуск:
```python
socketio.run(app)
```


---

## Особенности

- Работает поверх **Socket.IO**, а не чистого WebSocket → даёт дополнительный функционал (комнаты, fallback).
    
- Требует асинхронного сервера (eventlet/gevent) для масштабирования.
    
- Хорошо интегрируется с [[Flask-SQLAlchemy]], [[Flask-Login]] и др.
    
- Есть клиентские библиотеки для **JS, Android, iOS, C++**.
    

---

📌 **Итог**: Flask-SocketIO превращает Flask в real-time фреймворк: можно легко добавлять чаты, уведомления и другие интерактивные функции с двунаправленным обменом данными между клиентом и сервером.
