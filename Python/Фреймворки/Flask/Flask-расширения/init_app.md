# Flask: метод `init_app`

## Что это такое
- `init_app(app)` — это стандартный метод у **расширений [[Flask — базовый каркас|Flask]]** (например, `SQLAlchemy`, `Migrate`, `LoginManager` и др.).
- Он используется в **Application Factory Pattern** для инициализации расширений **без создания жёсткой зависимости** от конкретного экземпляра приложения.

## Зачем нужен
- Позволяет вынести создание приложения в отдельную фабрику (`create_app()`).
- Убирает глобальные зависимости: расширения создаются один раз, а инициализируются позже, когда будет готов объект `Flask`.

## Пример
```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy
from flask_migrate import Migrate

# Создаём расширения (без привязки к приложению)
db = SQLAlchemy()
migrate = Migrate()

def create_app():
    app = Flask(__name__)
    app.config.from_object("config.Config")  # Загружаем конфиг
    
    # Инициализация расширений
    db.init_app(app)
    migrate.init_app(app, db)
    
    return app
    ```


---
## Как работает

- Когда вызываешь `db.init_app(app)`, расширение читает настройки из `app.config` (например, `SQLALCHEMY_DATABASE_URI`) и настраивает подключение.
    
- Тот же принцип у других расширений: `init_app` регистрирует все необходимые обработчики, команды CLI, контекстные объекты и т.д.
    

## Паттерн использования

1. Создаёшь объект расширения глобально: `db = SQLAlchemy()`
    
2. Внутри `create_app()` делаешь `db.init_app(app)`
    
3. Теперь расширение связано с конкретным приложением.
    

## Преимущества

- Поддержка **нескольких приложений** в одном проекте (каждое можно проинициализировать отдельно).
    
- Код становится чище и модульнее.
    
- Соответствует best practices Flask.
