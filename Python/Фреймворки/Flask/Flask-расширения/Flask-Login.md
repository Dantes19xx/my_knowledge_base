## Что это

**Flask-Login** — расширение Flask для управления **аутентификацией пользователей**.  
Оно не занимается хранением паролей или регистрацией, а отвечает за:

- вход и выход пользователя,
    
- запоминание его в сессии,
    
- доступ к текущему пользователю (`current_user`).
    

---

## Основные возможности

- **Управление сессиями**
    
    - хранение информации о залогиненном пользователе
        
    - поддержка «запомнить меня» (remember me cookies)
        
- **Текущий пользователь**
    
    - глобальный объект `current_user` доступен во Flask и Jinja2
        
- **Декораторы**
    
    - `@login_required` — ограничение доступа к маршруту
        
- **Поддержка анонимных пользователей**
    
    - если пользователь не авторизован, `current_user.is_authenticated = False`
        
- **Интеграция с Flask-сессиями**
    
    - данные о пользователе хранятся безопасно (через ItsDangerous)
        

---

## Роль в Flask

- Flask-Login не реализует БД или регистрацию — это нужно делать вручную (или через другое расширение, например Flask-Security).
    
- Он только управляет **процессом входа и выхода**.
    

---

## Типичный рабочий процесс

1. Пользователь проходит аутентификацию (проверка логина/пароля).
    
2. Вызов `login_user(user)` сохраняет пользователя в сессии.
    
3. Во Flask доступен `current_user`.
    
4. Для выхода используется `logout_user()`.
    
5. Если доступ к маршруту ограничен:

```python
@login_required
def profile():
    return f"Hello, {current_user.username}"
```


---

## Особенности

- Простота интеграции
    
- Работает с любой моделью пользователя (ORM не навязан)
    
- Не занимается безопасностью паролей — это остаётся на стороне разработчика
    
- Часто используется в связке с:
    
    - **Flask-WTF** (формы логина/регистрации)
        
    - **Flask-Bcrypt** или **passlib** (хеширование паролей)
        
    - **Flask-Security** (готовая система auth + roles)

# Flask-Login — основные инструменты

## 1. `@login_required`

- **Что делает**: декоратор, который защищает маршрут.
    
- Если пользователь не аутентифицирован → его перенаправит на страницу логина (по умолчанию `login_view`).
    
- В шаблонах и функциях проверяется через `current_user.is_authenticated`.
    

📌 Пример сценария:

- Защита личного кабинета, API или админки.
    

---

## 2. `login_user(user, remember=False, duration=None, force=False, fresh=True)`

- **Что делает**: авторизует пользователя и сохраняет его в сессии.
    
- Аргументы:
    
    - `user` — объект пользователя (должен иметь `is_authenticated`, `is_active`, `is_anonymous`, `get_id()`).
        
    - `remember` — включить «запомнить меня» (через cookie).
        
    - `duration` — срок действия remember-cookie.
        
    - `force` — войти даже если `user.is_active == False`.
        
    - `fresh` — помечает логин как «свежий» (используется для защиты чувствительных операций).
        

📌 Пример сценария:

- Пользователь ввёл правильный логин/пароль → вызываем `login_user(user)`.
    

---

## 3. `logout_user()`

- **Что делает**: разлогинивает пользователя → очищает его сессию.
    
- После этого `current_user` станет анонимным (`AnonymousUserMixin`).
    

📌 Пример сценария:

- Кнопка «Выйти из аккаунта».
    

---

## 4. `current_user`

- **Что делает**: прокси-объект, который всегда указывает на «текущего пользователя».
    
- Если залогинен → возвращает объект пользователя (из твоей модели User).
    
- Если не залогинен → возвращает объект `AnonymousUserMixin`.
    

Доступные атрибуты:

- `current_user.is_authenticated` — True/False
    
- `current_user.is_active` — может ли пользователь входить
    
- `current_user.is_anonymous` — True, если не вошёл
    
- `current_user.get_id()` — ID пользователя (строка)
    

📌 Пример сценария:

- Проверка прав доступа, вывод имени пользователя в шаблоне.
    

---

## Итоговое сравнение

|Инструмент|Назначение|
|---|---|
|`@login_required`|Ограничивает доступ к маршруту только для залогиненных пользователей|
|`login_user()`|Авторизует пользователя и сохраняет в сессии|
|`logout_user()`|Завершает сессию, делает пользователя анонимным|
|`current_user`|Глобальный объект текущего пользователя (User или Anonymous)|

---
📌 **Итог**: Flask-Login — это «менеджер аутентификации» во Flask. Он облегчает управление сессиями, доступом и текущим пользователем, но требует интеграции с собственной системой хранения и проверки пользователей.

- `login_user()` и `logout_user()` управляют состоянием пользователя.
    
- `current_user` отражает текущее состояние (авторизован / аноним).
    
- `@login_required` ограничивает доступ к страницам.
