## Что это

**Flask-Breadcrumbs** — расширение Flask для автоматического создания и отображения **«хлебных крошек»** (_breadcrumbs navigation_).  
«Хлебные крошки» — это цепочка ссылок, показывающая путь пользователя внутри сайта:

```
Главная > Категория > Статья
```


---

## Основные возможности

- **Автоматическое формирование навигации**
    
    - добавляет «крошки» на основе маршрутов Flask
        
- **Интеграция с шаблонами Jinja2**
    
    - можно вставить в шаблон специальный блок для отображения цепочки
        
- **Поддержка вложенных маршрутов**
    
    - формирует древовидную структуру
        
- **Гибкая настройка**
    
    - можно задавать собственные названия пунктов, а не только из URL
        
- **Интеграция с Flask-Menu**
    
    - для расширенной навигации
        

---

## Роль во Flask

- Улучшает **UX** (удобнее навигация для пользователя)
    
- Позволяет не писать вручную «цепочку ссылок» в каждом шаблоне
    
- Подходит для админок, больших сайтов, CMS
    

---

## Типичный рабочий процесс

1. Подключение:
```python
from flask_breadcrumbs import Breadcrumbs, register_breadcrumb

Breadcrumbs(app=app)
```

2. Добавление к маршруту:

```python
@app.route('/profile')
@register_breadcrumb(app, '.', 'Профиль')
def profile():
    return render_template('profile.html')
```

3. В шаблоне:
```jinja2
{% for breadcrumb in breadcrumbs %}
    <a href="{{ breadcrumb.url }}">{{ breadcrumb.text }}</a>
{% endfor %}
```


---

## Особенности

- Работает «поверх» маршрутов Flask
    
- Поддерживает динамические параметры (например, `id` статьи)
    
- Можно комбинировать с Flask-Login (например, отдельные цепочки для разных пользователей)
    

---

📌 **Итог**: Flask-Breadcrumbs — это расширение для автоматизации навигации «хлебных крошек» в приложениях Flask. Полезно для структурированных сайтов и админок, экономит время на ручной разметке.
