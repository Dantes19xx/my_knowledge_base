## Что это

**Flask-Session** — расширение Flask, которое позволяет хранить сессионные данные **не только в cookies (по умолчанию у Flask)**, а на сервере:

- в [[Redis]],
    
- в Memcached,
    
- в файловой системе,
    
- в SQL-базе данных.
    

---

## Зачем нужно

По умолчанию Flask хранит сессию:

- **в cookie у клиента**
    
- данные подписываются через [[ItsDangerous]] (подделать нельзя, но можно увидеть)
    

👉 Это удобно для мелких приложений, но не всегда безопасно и ограничено по размеру (~4 КБ).

**Flask-Session** решает проблему:

- данные хранятся на сервере,
    
- в cookies сохраняется только идентификатор сессии,
    
- данные не видны пользователю и могут быть большими.
    

---

## Основные возможности

- **Хранение сессии на сервере**
    
- Поддержка разных бэкендов: [[Redis]], Memcached, MongoDB, SQLAlchemy, файловая система
    
- Совместимость с [[Flask-Login]] и другими расширениями
    
- Безопасность: пользователи не видят содержимое сессии
    

---

## Роль во Flask

- Делает сессии более **надёжными** и **масштабируемыми**
    
- Особенно полезно при **нагрузке** или в **кластерных приложениях**, где несколько Flask-серверов работают с одной базой/Redis


---

## Типичный рабочий процесс

1. Установка и инициализация:
```python
from flask import Flask, session
from flask_session import Session

app = Flask(__name__)
app.config["SECRET_KEY"] = "секретный_ключ"

# Настройка хранилища сессии
app.config["SESSION_TYPE"] = "redis"  # или "filesystem", "sqlalchemy" и т.д.

# Применить расширение
Session(app)
```

2. Использование в коде:
```python
@app.route("/set/")
def set_session():
    session["username"] = "dmitriy"
    return "Сессия сохранена!"

@app.route("/get/")
def get_session():
    return f"Пользователь: {session.get('username', 'Гость')}"
```


---

## Особенности

- Требует настройки бэкенда (например, Redis-сервер для `SESSION_TYPE="redis"`)
    
- Лучше подходит для production, чем стандартные cookie-сессии
    
- Может хранить больше данных и работать в распределённых системах
    

---

📌 **Итог**: Flask-Session — расширение, которое переводит хранение сессий с клиентских cookies на сервер (Redis, БД, файлы и др.), делая их более защищёнными и масштабируемыми.
