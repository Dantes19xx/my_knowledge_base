## Описание

**List comprehension** — это краткий и читаемый способ создания списков в Python. Позволяет заменить многострочные циклы `for` на однострочные выражения.

Синтаксис:

```python
[выражение for элемент in итерируемый_объект if условие]
```

## Примеры

### 1. Создание списка квадратов

```python
squares = [x * x for x in range(5)] # [0, 1, 4, 9, 16]
```

### 2. Отбор чётных чисел

```python
evens = [x for x in range(10) if x % 2 == 0] # [0, 2, 4, 6, 8]
```

### 3. Преобразование строк в числа

```python
str_numbers = ['1', '2', '3'] int_numbers = [int(s) for s in str_numbers] # [1, 2, 3]
```

### 4. Вложенные циклы

```python
pairs = [(x, y) for x in range(3) for y in range(2)] # [(0, 0), (0, 1), (1, 0), (1, 1), (2, 0), (2, 1)]
```


---

### Эквивалент с `for`-циклом

```python
# comprehension
squares = [x * x for x in range(5)]

# эквивалентный код
squares = []
for x in range(5):
    squares.append(x * x)
```

## Когда использовать

- Нужно создать **новый список** на основе другого итерируемого объекта.
    
- Преобразование, фильтрация, упрощение логики.
    
- Улучшение читаемости при простой логике.
    

---

## Когда НЕ использовать

- Сложная логика или вложенные условия → ухудшается читаемость.
    
- Когда важна **память** — list comprehension сразу создаёт весь список (в отличие от генераторов).

## Связанные темы

- `generator expression` → `(x for x in iterable)` (ленивый аналог)
