## Описание

**Generator expression** — это компактный способ создания генераторов, аналогичный `list/set comprehension`, но не создающий структуру в памяти.  
Он **ленивый** — элементы вычисляются по мере запроса.

Синтаксис:

```python
(expression for item in iterable if condition)
```

🔹 В отличие от `[]`, используется **круглая скобка** `()`  
🔹 Возвращает **генератор** (тип `generator`), а не список/множество.

---

## ✅ Примеры

### 1. Квадраты чисел

```python
squares = (x * x for x in range(5)) print(next(squares))  # 0 print(list(squares))  # [1, 4, 9, 16]
```

### 2. Сумма квадратов чётных чисел

```python
total = sum(x * x for x in range(10) if x % 2 == 0) # 0 + 4 + 16 + 36 + 64 = 120
```

### 3. Преобразование строк в числа (лениво)

```python
str_numbers = ['1', '2', '3'] int_gen = (int(s) for s in str_numbers)  for n in int_gen:     print(n) # 1 2 3
```

---

## ⚙️ Эквивалент с `for`-циклом

```python
# генераторное выражение
evens = (x for x in range(10) if x % 2 == 0)

# обычный генератор через функцию
def evens_gen():
    for x in range(10):
        if x % 2 == 0:
            yield x
```

---

## 💡 Когда использовать

- Обработка **больших объёмов данных** без загрузки в память.
    
- Когда нужен **ленивый** итерируемый объект.
    
- В связке с функциями `sum()`, `any()`, `all()`, `max()` и т.п.
    

---

## 🛑 Когда НЕ использовать

- Если нужно многократно проходиться по данным (генератор можно итерировать только один раз).
    
- Для операций, где требуется **индексация** или **полный список значений**.
    

---

## 🧠 Связанные темы

- [[List Comprehension]] → `[x for x in iterable]`
    
- [[Set Comprehension]] → `{x for x in iterable}`
    
- [[Dict Comprehension]] → `{k: v for k, v in iterable}`
    
- yield и генераторы-функции
