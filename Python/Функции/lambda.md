# Лямбда-функции в Python

## 📘 Что такое `lambda`?

`lambda` — это способ объявления **анонимной функции** (без имени) в Python.  
Обычно используется для коротких функций, которые удобно передавать как аргументы.

---

## 🔧 Синтаксис

```python
lambda аргументы: выражение
lambda — ключевое слово
```


аргументы — как в обычной функции

выражение — возвращаемое значение (должно быть одним выражением, без return)


---
## Примеры

### Пример 1: сложение двух чисел

```python
add = lambda x, y: x + y print(add(2, 3))  # 5
```

### Пример 2: использование с `sorted()`

```python
items = [(1, 'b'), (2, 'a'), (3, 'c')] 
sorted_items = sorted(items, key=lambda x: x[1]) # [(2, 'a'), (1, 'b'), (3, 'c')]
```

### Пример 3: с [[map]]()

```python
numbers = [1, 2, 3] 
squared = list(map(lambda x: x ** 2, numbers)) # [1, 4, 9]
```



---

## Где применяются

- В `map()`, `filter()`, `reduce()`
    
- В `sorted()` для сортировки по ключу
    
- В GUI-коллбэках и функциях обратного вызова
    
- В генерации простых функций на месте
    

---

## 🚫 Ограничения

- Только **одно выражение** — нельзя использовать `if`, `for`, `while` как в теле обычной функции
    
- Нет имени — не всегда удобно отлаживать
    
- Не читается, если логика сложная
