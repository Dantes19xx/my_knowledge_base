`map()` — встроенная функция Python, которая применяет заданную функцию к каждому элементу итерируемого объекта (например, списка, кортежа) и возвращает итератор с результатами.


---
```python
map(function, iterable, ...)
```

- **function** — функция, которая применяется к каждому элементу.
    
- **iterable** — один или несколько итерируемых объектов (список, кортеж и т.д.).
---

## Особенности

- `map` **ленивая** — возвращает итератор. Чтобы увидеть результат, часто оборачивают в `list()`.
    
- Если передано несколько итерируемых, функция должна принимать соответствующее количество аргументов.


---

## Примеры использования

### 1. Преобразование всех чисел в квадрат

```python
def square(x):
    return x * x

numbers = [1, 2, 3, 4, 5]
squared = map(square, numbers)
print(list(squared))  # [1, 4, 9, 16, 25]
```

### 2. Использование с `lambda`

```python
numbers = [1, 2, 3]
result = list(map(lambda x: x + 10, numbers))
print(result)  # [11, 12, 13]
```

### 3. Преобразование строк в числа

```python
str_numbers = ['1', '2', '3']
int_numbers = list(map(int, str_numbers))
print(int_numbers)  # [1, 2, 3]
```

### 4. Работа с несколькими списками

```python
a = [1, 2, 3]
b = [10, 20, 30]
sums = list(map(lambda x, y: x + y, a, b))
print(sums)  # [11, 22, 33]
```


---
## Когда использовать `map`

- Когда нужно **преобразовать** каждый элемент итерируемого объекта.
    
- Если важна **производительность**, т.к. `map` не создаёт промежуточных списков.
    
- Вместо `for`-циклов для более функционального и компактного кода.


---

### Альтернатива — [[List Comprehension]]

```python
# map
result = list(map(lambda x: x * 2, [1, 2, 3]))

# list comprehension (аналог)
result = [x * 2 for x in [1, 2, 3]]
```

Обычно list comprehension читается проще, но `map` удобен при повторном использовании одной функции.


---

## Вывод

- Если ты используешь **встроенную функцию**, например `str`, `int`, `len`, то **`map()` будет немного быстрее**.
    
- Если ты используешь **`lambda` или кастомную логику**, то **list comprehension** будет не только **быстрее**, но и **более читаемой**.
    
- Для **сложной логики или фильтрации** — предпочтительнее comprehension.
