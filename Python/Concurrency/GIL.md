
Что такое GIL

GIL — это механизм в интерпретаторе CPython, который ограничивает выполнение только одного потока Python-кода в один момент времени, даже на многоядерных процессорах.

Важно: GIL — не часть языка Python, а особенность реализации CPython (стандартной реализации Python).

🔧 Зачем нужен GIL

- CPython использует счётчик ссылок для управления памятью объектов.
- GIL гарантирует, что только один поток изменяет объекты в памяти в любой момент времени, чтобы избежать гонок данных и падений.
