## 📌 Наследование (Inheritance) в ООП

**Наследование** — это механизм объектно-ориентированного программирования, позволяющий создавать новый класс (**дочерний**, _subclass_) на основе уже существующего (**родительского**, _superclass_), перенимая его **свойства и методы**.

Это помогает:

- **Избегать дублирования кода**
    
- **Повторно использовать логику**
    
- **Строить иерархии классов**
    
- **Расширять или переопределять функциональность**
    

---

### 1. **Виды наследования**

В Python есть несколько форм:

|Вид наследования|Пример|Описание|
|---|---|---|
|**Одиночное**|`class Dog(Animal)`|Один родитель|
|**Множественное**|`class Amphibian(Frog, Fish)`|Несколько родителей|
|**Многоуровневое**|`class Poodle(Dog)`|Наследование в цепочке|
|**Иерархическое**|`class Cat(Animal)`, `class Dog(Animal)`|Один родитель, несколько дочерних|
|**Гибридное**|Комбинация всех выше|Смешанный тип|

### 2. **Синтаксис в Python**

```python
class Animal:
    def speak(self):
        print("Animal makes a sound")

# Дочерний класс
class Dog(Animal):
    def speak(self):  # Переопределение метода
        print("Dog barks")

dog = Dog()
dog.speak()  # Dog barks
```

### 3. **Ключевые возможности**

#### 🔹 Переопределение методов

Дочерний класс может изменить реализацию родительского метода:

```python
class Animal:
    def speak(self):
        print("Some sound")

class Cat(Animal):
    def speak(self):
        print("Meow")

Cat().speak()  # Meow
```

#### 🔹 Расширение методов с помощью `super()`

```python
class Animal:
    def speak(self):
        print("Animal sound")

class Dog(Animal):
    def speak(self):
        super().speak()  # вызов метода родителя
        print("Bark")

Dog().speak()
# Animal sound
# Bark
```

#### 🔹 Наследование атрибутов

```python
class Vehicle:
    wheels = 4

class Car(Vehicle):
    pass

print(Car.wheels)  # 4
```


### 4. **Множественное наследование и MRO**

При множественном наследовании Python использует **Method Resolution Order (MRO)** для поиска методов.  
Проверить порядок можно так:

```python
class A: pass
class B(A): pass
class C(A): pass
class D(B, C): pass

print(D.mro())
# [<class '__main__.D'>, <class '__main__.B'>, <class '__main__.C'>, <class '__main__.A'>, <class 'object'>]
```

### 5. **Проблемы наследования**

- Слишком глубокая иерархия усложняет код
    
- Множественное наследование может вызывать конфликты имён
    
- Жёсткая связность между классами
    

📌 Иногда **лучше использовать композицию**, чем наследование (принцип _composition over inheritance_).

---

### 6. **Когда применять наследование**

✅ Когда есть **реальная** иерархическая связь _"is-a"_  
❌ Не использовать для просто заимствования кода (тогда лучше **композиция**)

Примеры корректного применения:

- `Car` → `Vehicle`
    
- `Square` → `Rectangle`
    
- `AdminUser` → `User`
