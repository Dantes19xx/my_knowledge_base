# Продвинутое ООП в Python — Основной синтаксис (Python Core Syntax)

## Что такое core syntax?

Core syntax — это набор синтаксических конструкций и встроенных возможностей Python, позволяющих выполнять операции над различными типами данных с использованием одних и тех же операторов, функций и выражений.

Примеры:

- Арифметические операторы: `+`, `-`, `*`, `/`, `%` и т.д.
- Операторы сравнения: `==`, `<`, `>`, `<=`, `in` и т.д.
- Индексация, срезы: `obj[0]`, `obj[1:3]`
- Встроенные функции: `str()`, `len()`, `sum()`
- Рефлексия: `isinstance()`, `issubclass()`

## [[Категории dunder-методов|Dunder-методы]]

Каждому оператору в Python соответствует специальный **магический метод** (dunder — double underscore). Примеры:

| Оператор | Магический метод |
|----------|------------------|
| `+`      | `__add__`        |
| `-`      | `__sub__`        |
| `*`      | `__mul__`        |
| `/`      | `__truediv__`    |
| `==`     | `__eq__`         |
| `in`     | `__contains__`   |

### Пример: использование `__add__`

```python
number = 10

print(number + 20)           # 30
print(number.__add__(20))    # 30
```

Обе строки делают одно и то же — вызывают `__add__`.

## Переопределение dunder-методов

В классе можно переопределить dunder-методы для задания своей логики поведения операторов:

```python
class Person:
    def __init__(self, weight, age, salary):
        self.weight = weight
        self.age = age
        self.salary = salary

    def __add__(self, other):
        return self.weight + other.weight

p1 = Person(30, 40, 50)
p2 = Person(35, 45, 55)

print(p1 + p2)  # 65
```

- В примере выше оператор `+` применён к экземплярам `Person`, и благодаря `__add__` возвращает сумму их веса.
    
- При этом сами атрибуты экземпляров не изменяются.

## Исследование объектов с помощью `dir()`
```python
print(dir(p1))
```

- Функция `dir()` показывает список всех атрибутов и методов объекта, включая магические методы (`__add__`, `__str__` и т.д.).
    
- Полезно для изучения интерфейса объектов и доступных переопределений.

## Выводы

- Dunder-методы позволяют переопределить стандартное поведение операторов и функций.
