# Продвинутое ООП в Python — Данные класса и экземпляра

## Данные класса

- **Определяются на уровне класса**.
- Общие для всех экземпляров.
- Существуют в единственном экземпляре вне зависимости от количества объектов.
- Не отображаются в `__dict__` экземпляра, но доступны через него.

```python
class Demo:
    class_var = 'shared variable'

d1 = Demo()
d2 = Demo()

print(d1.class_var)  # shared variable
print(d2.class_var)  # shared variable
print(Demo.class_var)  # shared variable
```


### Изменение переменной класса

- **Правильный способ** — через имя класса:
```python
Demo.class_var = 'new value'
```

- Если изменить через экземпляр, создаётся **новая переменная экземпляра**:
```python
d1.class_var = 'instance value'
print(d1.class_var)  # instance value
print(Demo.class_var)  # new value
print(d1.__dict__)  # {'class_var': 'instance value'}
```

## Данные экземпляра

- Уникальны для каждого экземпляра.
    
- Определяются внутри `__init__` или других методов через `self`.
```python
class Demo:
    def __init__(self, value):
        self.instance_var = value

d1 = Demo(1)
d2 = Demo(2)

print(d1.instance_var)  # 1
print(d2.instance_var)  # 2
```

## Комбинация данных класса и экземпляра

- Часто используется для метаинформации, счётчиков, кешей и т.д.
```python
class User:
    user_count = 0

    def __init__(self, name):
        self.name = name
        User.user_count += 1

u1 = User("Alice")
u2 = User("Bob")

print(User.user_count)  # 2
```

## Использование `super()` для вызова конструктора суперкласса

```python
class Phone:
    def __init__(self, number):
        self.number = number

class FixedPhone(Phone):
    last_SN = 0

    def __init__(self, number):
        super().__init__(number)
        FixedPhone.last_SN += 1
        self.serial = FixedPhone.last_SN
```

- Вызов `super().__init__(...)` гарантирует, что инициализация родительского класса выполнится корректно.
    
- Полезно при наследовании и работе с иерархией классов.

## Полезные функции

- `vars(obj)` — возвращает `__dict__` объекта.
    
- `dir(obj)` — возвращает все доступные атрибуты объекта.
    
- `isinstance(obj, cls)` — проверка принадлежности экземпляра классу.
