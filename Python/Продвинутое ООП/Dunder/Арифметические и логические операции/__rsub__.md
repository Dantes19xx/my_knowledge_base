### Назначение

Метод `__rsub__` (Right Subtract) в Python используется для перегрузки операции вычитания, когда объект находится **справа** от оператора `-`. Если для левого операнда не определён метод `__sub__` или он возвращает `NotImplemented`, Python вызовет `__rsub__` правого операнда.

---
## Сигнатура

```python
def __rsub__(self, other):
    # реализация
```


---
## Пример использования

```python
class MyNumber:
    def __init__(self, value):
        self.value = value

    def __rsub__(self, other):
        return other - self.value

a = MyNumber(5)
result = 10 - a  # Вызовется a.__rsub__(10)
print(result)    # 5
```


---
### Сценарии использования

- Когда нужно определить нестандартное поведение для выражений вида `число - объект`.
    
- Часто используется в классах, моделирующих числа или вектора.
    

### Особенности

- Вызывается только если левый операнд не знает, как выполнить вычитание с данным объектом.
    
- Позволяет реализовать симметричные и асимметричные арифметические операции.
