# `__isub__` — дандер-метод для оператора `-=`

## Что это
`__isub__` — это специальный метод в Python, который вызывается при использовании оператора `-=`. Отвечает за **изменение объекта на месте** (in-place subtraction).

## Сигнатура
```python
def __isub__(self, other): ...
```


## Как работает

- Если метод `__isub__` реализован, то при выражении `a -= b` вызывается `a.__isub__(b)`.
    
- Если не реализован, Python пытается использовать `__sub__` и затем делает `a = a - b`.

```python
class Counter:
    def __init__(self, value):
        self.value = value

    def __isub__(self, other):
        print(f"Вычитаем {other} из {self.value}")
        self.value -= other
        return self

    def __repr__(self):
        return f"Counter({self.value})"

c = Counter(10)
c -= 3  # Вызовет __isub__
print(c)  # Counter(7)
```

## Отличие от `__sub__`

|Метод|Поведение|
|---|---|
|`__sub__`|Возвращает новый объект|
|`__isub__`|Изменяет текущий объект|

## Когда использовать

Используется в мутабельных типах, когда нужно изменить объект "на месте":

- Счётчики
    
- Матрицы
    
- Коллекции (списки, множества и т.п.)
