# Dunder методы: арифметические операции

## Назначение

Арифметические dunder-методы позволяют **переопределять поведение математических операторов** (`+`, `-`, `*`, `/`, `%`, `**`, `//` и др.) для пользовательских объектов.

---

## Основные методы

| Оператор | Dunder-метод                | Описание                           |
| -------- | --------------------------- | ---------------------------------- |
| `+`      | [[__add__]](self, other)    | Сложение                           |
| `-`      | [[__sub__]](self, other)    | Вычитание                          |
| `*`      | [[__mul__]](self, other)    | Умножение                          |
| `/`      | `__truediv__(self, other)`  | Деление (float)                    |
| `//`     | `__floordiv__(self, other)` | Целочисленное деление              |
| `%`      | `__mod__(self, other)`      | Остаток от деления                 |
| `**`     | `__pow__(self, other)`      | Возведение в степень               |
| `@`      | `__matmul__(self, other)`   | Мат. умножение (`@` в Python 3.5+) |
eq

---

## Обратные методы

Вызываются, если левый операнд не реализует соответствующий метод.

| Оператор | Метод                              | Описание                                       |
| -------- | ---------------------------------- | ---------------------------------------------- |
| `+`      | [[__radd__]]                       | Обратное сложение (если `__add__` не работает) |
| `-`      | [[__rsub__]]                       | Обратное вычитание                             |
| и т.д.   | `__rmul__`, `__rtruediv__`, и т.д. | Аналогично другим операциям                    |

---

## Методы in-place операций

Используются для операций с присваиванием (`+=`, `-=`, `*=`, и т.д.)

| Оператор | Метод                             | Описание                    |
| -------- | --------------------------------- | --------------------------- |
| `+=`     | [[__iadd__]]                      | In-place сложение           |
| `-=`     | `__isub__`                        | In-place вычитание          |
| `*=`     | `__imul__`                        | In-place умножение          |
| и т.д.   | `__itruediv__`, `__imod__`, и др. | Аналогично другим операциям |
