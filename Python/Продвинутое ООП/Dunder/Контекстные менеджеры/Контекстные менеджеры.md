# Dunder-методы контекста в Python (`__enter__`, `__exit__`)

## 📘 Что это такое?

Методы [[__enter__]] и [[__exit__]] — это специальные методы в Python, также называемые **dunder-методами** (от "double underscore").  
Они позволяют объекту быть **контекстным менеджером** — то есть использоваться с конструкцией `with`.

---

## 🧩 Назначение

Контекстные менеджеры управляют ресурсами, которые нужно явно открывать и закрывать (например, файлы, соединения, транзакции).  
Конструкция `with` автоматически вызывает:

- `__enter__` — при входе в блок
- `__exit__` — при выходе из блока (даже если возникло исключение)

---

## ✅ Когда использовать?

Когда необходимо:
- Гарантированно освободить ресурсы
- Автоматизировать логику входа/выхода из блока
- Обернуть блок кода в безопасную структуру (например, работа с файлами, соединениями)

---

## 🛠 Где встречается?

- `with open(...) as f:` — работа с файлами
- Подключение к БД: `with connection.cursor() as cursor:`
- Работа с потоками, блокировками, транзакциями
- Собственные классы-контексты с ресурсами
