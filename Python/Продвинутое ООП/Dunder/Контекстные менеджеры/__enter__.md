# Метод `__enter__` в Python

## 📘 Что это?

`__enter__` — это специальный метод (так называемый *dunder method*, от **"double underscore"**), который вызывается автоматически при входе в блок `with` в контекстном менеджере.

Он **должен быть реализован**, если объект используется как контекстный менеджер (вместе с [[__exit__]]).

---

## 🔧 Сигнатура

```python
def __enter__(self) -> Any:
    ...
```

- Возвращаемое значение передаётся переменной в конструкции `with ... as ...`.
    
- Этот метод отвечает за _инициализацию контекста_ — открытие ресурса, установка соединения и т. д.


---
## Пример 1: Файловый контекст (за кулисами)

```python
with open("example.txt") as f:     data = f.read()
```

Внутри `open()` возвращает объект с методами `__enter__` и `__exit__`. Он делает примерно следующее:

```python
f = open("example.txt") f.__enter__() try:     data = f.read() finally:     f.__exit__(None, None, None)
```

## Что может делать `__enter__`?

- Открывать соединения (файл, БД, сеть)
    
- Запускать таймеры, логгеры
    
- Устанавливать временное состояние (например, менять глобальные настройки)
    
- Возвращать объект (например, дескриптор файла или соединения)
    

---

## ❗Важно

- **Обязательно** реализовывать вместе с `__exit__` — иначе `with` не будет работать корректно.
    
- Если не нужен объект внутри блока `as`, всё равно `__enter__` должен быть.
