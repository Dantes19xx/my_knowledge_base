# Метод `__exit__` в Python

## 📘 Что это?

`__exit__` — это специальный метод контекстного менеджера, который вызывается **при выходе** из блока `with`, **вне зависимости от того, была ли ошибка**.

Он отвечает за **завершение и очистку**: закрытие файла, соединения, откат транзакции, освобождение ресурсов и т.п.

---

## 🔧 Сигнатура

```python
def __exit__(self, exc_type, exc_val, exc_tb) -> bool:
    ...
```

### Аргументы:

- `exc_type` — тип исключения (например, `ValueError`)
    
- `exc_val` — экземпляр исключения (объект ошибки)
    
- `exc_tb` — traceback (информация о стеке вызовов)
    

Если **внутри блока `with` произошла ошибка**, они будут заполнены. Если нет — все три будут `None`.

### Возвращаемое значение:

- Если `__exit__` вернёт **True**, исключение **подавляется**.
    
- Если **False или None** — исключение пробрасывается дальше.


---

## Когда вызывается?

- При **нормальном завершении** блока `with`
    
- При **возникновении исключения** — сразу после
    

---

## 🧠 Что можно делать внутри `__exit__`?

- Закрытие файлов и соединений
    
- Освобождение ресурсов
    
- Логирование ошибок
    
- Подавление ошибок (если это допустимо)
    
- Откат транзакций
    

---

## 🛑 Подавление исключений

Если ты **возвращаешь `True`** из `__exit__`, ты говоришь Python: _"всё под контролем, исключения нет"_.

**Пример:**

```python
def __exit__(self, exc_type, exc_val, exc_tb):     
	return True  # Ошибка не выйдет за пределы блока
```
