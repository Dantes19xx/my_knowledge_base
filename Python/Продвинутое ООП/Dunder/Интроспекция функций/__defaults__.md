# `__defaults__` в Python

## 📂 Категория: Python / Внутренности функций / Интроспекция

---

## 🧠 Что такое `__defaults__`

`__defaults__` — это специальное внутреннее свойство (дандер) объекта функции, которое хранит **значения по умолчанию для позиционных аргументов** функции.

---

## 🔍 Как это работает

Когда ты определяешь функцию с аргументами по умолчанию:

```python
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"
```

Python сохраняет значение `"Hello"` в кортеж `greet.__defaults__`.

```python
print(greet.__defaults__)  # ('Hello',)
```


---

## 🧪 Пример с изменением `__defaults__`

Ты можешь изменить поведение функции во время выполнения, подменив значения по умолчанию:

```python
def foo(x=1):
    return x

print(foo())  # 1

foo.__defaults__ = (42,)
print(foo())  # 42
```

⚠️ Это возможно, но **не рекомендуется** использовать в продакшене — может привести к неочевидным багам.

---

## ⚙️ Ключевые особенности

- Хранит **только позиционные** параметры с default'ами.
    
- Значение — это **кортеж**.
    
- Порядок соответствует порядку аргументов в сигнатуре функции.
    
- Если параметров по умолчанию нет — `__defaults__ == None`.

## 📎 Связанные свойства

| Свойство         | Описание                                                        |
| ---------------- | --------------------------------------------------------------- |
| `__defaults__`   | Значения по умолчанию для позиционных аргументов                |
| `__kwdefaults__` | Значения по умолчанию для именованных аргументов (keyword-only) |

---

## 🧬 Пример с позиционными и именованными аргументами

```python
def f(a, b=2, *, c=3):
    pass

print(f.__defaults__)     # (2,)
print(f.__kwdefaults__)   # {'c': 3}
```

- Интроспекция и отладка функций

- Разработка фреймворков
