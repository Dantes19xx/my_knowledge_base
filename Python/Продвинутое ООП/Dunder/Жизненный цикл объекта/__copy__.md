# Dunder Method: __copy__

## Назначение

Метод `__copy__` используется для **поверхностного копирования** объекта. Вызывается модулем `copy`, когда применяется функция `copy.copy(obj)`.

---

## Сигнатура
```python
def __copy__(self):
```

- Принимает только `self`.
    
- Должен **вернуть новый объект** с копированными значениями полей (обычно поверхностно — ссылки на те же объекты).


---

## Зачем нужен

- Позволяет контролировать, **как копируются экземпляры** пользовательских классов.
    
- По умолчанию Python пытается копировать через `__reduce__`, что может быть неэффективно или некорректно для сложных объектов.

## Пример

```python
import copy

class Person:
    def __init__(self, name, data):
        self.name = name
        self.data = data

    def __copy__(self):
        print("Вызван __copy__")
        return Person(self.name, self.data)

p1 = Person("Alice", {"age": 30})
p2 = copy.copy(p1)

print(p1 is p2)              # False
print(p1.data is p2.data)    # True (поверхностная копия)
```


## Поверхностное vs глубокое копирование

| Тип копирования  | Описание                                |
| ---------------- | --------------------------------------- |
| `__copy__`       | Поверхностное копирование (`copy.copy`) |
| [[__deepcopy__]] | Глубокое копирование (`copy.deepcopy`)  |

- Поверхностное копирование копирует **ссылки** на вложенные объекты.
    
- Глубокое копирование создает **полные копии** вложенных объектов.
    

---

## Когда использовать

- Когда нужно точно задать, **какие поля копировать**, и как это делать.
    
- Когда нельзя использовать `copy.copy` по умолчанию из-за побочных эффектов.


---

## Пример: кастомное поведение

```python
class SmartList:
    def __init__(self, items):
        self.items = items

    def __copy__(self):
        print("Копируем только первые 2 элемента")
        return SmartList(self.items[:2])

import copy
lst = SmartList([1, 2, 3, 4])
new_lst = copy.copy(lst)
print(new_lst.items)  # [1, 2]
```
