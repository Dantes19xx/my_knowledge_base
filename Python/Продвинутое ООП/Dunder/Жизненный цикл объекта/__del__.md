# Dunder Method: __del__

## Назначение

Метод `__del__` — это **финализатор** (или деструктор), который вызывается **перед уничтожением объекта** сборщиком мусора. Используется для освобождения ресурсов: закрытия файлов, сетевых соединений и т.д.

---

## Сигнатура

```python
def __del__(self):
```

- Принимает только один аргумент — `self`.
    
- Не возвращает значение.
    
- Вызывается **автоматически**, когда объект удаляется из памяти (но **не гарантированно** сразу при `del`).


---

## Простой пример

```python
class Resource:
    def __init__(self, name):
        self.name = name
        print(f"{self.name} создан")

    def __del__(self):
        print(f"{self.name} удалён")

r = Resource("Объект A")
del r  # Явный вызов удаления (не обязательно вызовет __del__ сразу)
```

## Особенности

- `__del__` **не гарантируется к вызову**. Его поведение зависит от работы **сборщика мусора Python (GC)**.
    
- В случае **циклических ссылок**, `__del__` может не вызваться.
    
- Если внутри `__del__` произойдёт исключение, оно будет **подавлено**.


---

## Пример: закрытие файла

```python
class FileHandler:
    def __init__(self, filename):
        self.file = open(filename, 'w')

    def write(self, data):
        self.file.write(data)

    def __del__(self):
        print("Закрытие файла")
        self.file.close()

f = FileHandler("log.txt")
f.write("Лог\n")
```

*Лучше использовать `with` и `__enter__`/`__exit__` вместо `__del__` для управления ресурсами.*


---

## Почему стоит избегать `__del__`

- У объектов с `__del__` Python не может корректно управлять памятью, если есть **взаимные ссылки**.
    
- Контроль времени вызова невозможен — `__del__` вызывается **непредсказуемо**.
    
- При завершении программы порядок удаления объектов не гарантируется.


---

## Альтернатива — контекстный менеджер

```python
class Resource:
    def __enter__(self):
        print("Ресурс получен")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        print("Ресурс освобожден")

with Resource():
    print("Работа с ресурсом")
```
