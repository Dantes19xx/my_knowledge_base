# Dunder Method: __repr__

## Назначение

Метод `__repr__` отвечает за **официальное строковое представление** объекта.  
Цель — отдать строку, которая **однозначно описывает объект**, желательно так, чтобы её можно было использовать в `eval()` для воссоздания объекта (если это возможно).

---

## Сигнатура
```python
def __repr__(self) -> str:
```

*Должен возвращать **строку**, описывающую объект с технической точки зрения.*


---

## Когда вызывается

| Ситуация                       | Поведение                             |
| ------------------------------ | ------------------------------------- |
| `repr(obj)`                    | Вызывает `obj.__repr__()`             |
| В интерактивной оболочке       | Результат последней строки = `repr()` |
| Если [[__str__]] не определён  | `print(obj)` вызывает `__repr__()`    |
| В контейнерах (`list`, `dict`) | Отображает элементы через `__repr__`  |
## Пример

```python
class Book:
    def __init__(self, title, author):
        self.title = title
        self.author = author

    def __repr__(self):
        return f'Book(title="{self.title}", author="{self.author}")'

b = Book("1984", "George Orwell")
print(repr(b))  # Book(title="1984", author="George Orwell")
```


---
## Сравнение с `__str__`

| Метод      | Назначение                  | Используется в                            |
| ---------- | --------------------------- | ----------------------------------------- |
| `__str__`  | Пользовательский вывод      | `str()`, `print()`, `f"{obj}"`            |
| `__repr__` | Отладка / технический вывод | `repr()`, интерактивный режим, контейнеры |

Если `__str__` отсутствует, `__repr__` используется вместо него.



---

## Пример: оба метода

```python
class Person:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"{self.name}"

    def __repr__(self):
        return f'Person(name="{self.name}")'

p = Person("Alice")
print(p)           # Alice
print(repr(p))     # Person(name="Alice")
```

---

## Почему `__repr__` важен

- Очень полезен при отладке: объекты в списках, словарях и в логах отображаются через `__repr__`.
    
- Желательно, чтобы `eval(repr(obj))` был валиден (если это возможно и безопасно).


---

## Если `__repr__` не задан

Поведение по умолчанию:

```python
<__main__.MyClass object at 0x7fd3a4c8>
```
