## Что это такое

**[[Поверхностное копирование]] (shallow copy)** — это процесс создания нового объекта, в который копируются **ссылки** на те же вложенные объекты, что и в оригинале. То есть верхний уровень копируется, а вложенные структуры **не дублируются**, а **разделяются** между копией и оригиналом.

## Как создать поверхностную копию

### 1. С помощью среза (для списков)

```python
original = [1, 2, 3]
shallow = original[:]
```

### 2. С помощью функции `list()`

```python
original = [1, 2, 3] shallow = list(original)
```


### 3. С помощью модуля `copy`

```python
import copy  
original = [[1, 2], [3, 4]] 
shallow = copy.copy(original)
```


## Пример: поведение поверхностной копии

```python
import copy

original = [[1, 2], [3, 4]]
shallow = copy.copy(original)

shallow[0][0] = 99

print(original)  # [[99, 2], [3, 4]]
print(shallow)   # [[99, 2], [3, 4]]
```


- Хотя `shallow` — это новая структура верхнего уровня, вложенные списки `[1, 2]` и `[3, 4]` остаются **общими** между `original` и `shallow`.
    
- Изменения во вложенных объектах отражаются в обоих списках.
    

## Когда использовать

- Поверхностное копирование удобно, когда:
    
    - нужно быстро скопировать структуру без глубокой вложенности,
        
    - нет необходимости изолировать вложенные объекты.
        

## Отличие от глубокого копирования

| Вид копирования                                      | Что копируется           | Общие вложенные объекты |
| ---------------------------------------------------- | ------------------------ | ----------------------- |
| Поверхностное                                        | Верхний уровень (ссылки) | Да                      |
| [[Глубокое копирование\|Глубокое]] (`copy.deepcopy`) | Вся структура рекурсивно | Нет                     |
