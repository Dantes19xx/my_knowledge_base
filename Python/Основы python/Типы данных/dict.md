`dict` (словарь) — это встроенная структура данных в Python, реализованная на основе [[Хэш-таблицы|хэш-таблицы]]. Он позволяет хранить пары ключ-значение и обеспечивает быстрый доступ к значениям по ключу.

`dict` — это полноценный **тип данных**, реализованный как класс `dict`.

## Основные свойства `dict`

| Свойство          | Описание                                                                                      |
| ----------------- | --------------------------------------------------------------------------------------------- |
| Тип               | `class 'dict'`                                                                                |
| Основа            | Хэш-таблица                                                                                   |
| Порядок элементов | Сохраняется с версии Python 3.7                                                               |
| Ключи             | Только хэшируемые и неизменяемые объекты                                                      |
| Доступ по ключу   | Средняя сложность `O(1)`                                                                      |
| Методы            | `.get()`, `.setdefault()`, `.update()`, `.pop()`, `.keys()`, `.values()`, `.items()` и другие |

---

## Где `dict` в общей системе типов Python

Python имеет следующие встроенные типы данных:

- Примитивы: `int`, `float`, `bool`, `str`
    
- Коллекции: `list`, `tuple`, `set`, `dict`
    
- Специальные: `NoneType`, `bytes`, `frozenset`, и др.
    

---

## Связь с хэш-таблицей

Внутри `dict` реализован с помощью хэш-таблицы:

- Каждый ключ проходит через [[Хэш-функция|хэш-функцию]] (`hash()`)
    
- Полученный хэш используется для вычисления позиции в памяти
    
- Разрешение [[Коллизии в хэш-функциях|коллизий]] осуществляется с помощью открытой адресации
