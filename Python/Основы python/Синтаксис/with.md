# Контекстный менеджер в Python

## 📌 Что такое контекстный менеджер?

Контекстный менеджер — это конструкция, которая управляет входом в блок кода и выходом из него, обеспечивая автоматическое выполнение операций до и после этого блока.

Обычно используется с ключевым словом `with`.

## 📘 Синтаксис

```python
with <контекстный_менеджер> as <переменная>:
    # блок кода
```


---

### Пример с файлом:

```python
with open('example.txt', 'r') as f:     content = f.read()
```

Этот код:

- откроет файл
    
- присвоит файловый объект переменной `f`
    
- закроет файл автоматически после выхода из блока `with`
    

## 🔧 Как работает?

Контекстный менеджер реализует методы:

- [[__enter__]](self) — вызывается при входе в блок `with`
    
- [[__exit__]](self, exc_type, exc_val, exc_tb) — вызывается при выходе (даже при ошибке)

## Для чего использовать?

- Работа с файлами (`open`)
    
- Работа с ресурсами: соединения с БД, сокеты
    
- Управление транзакциями
    
- Логирование и отладка
    
- Управление блокировками и потоками
