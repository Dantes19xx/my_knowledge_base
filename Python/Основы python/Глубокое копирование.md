# Глубокое копирование в Python

## Что такое глубокое копирование

**Глубокое копирование (deep copy)** — это способ создания полной независимой копии объекта, включая все вложенные структуры. В отличие от [[Поверхностное копирование|поверхностного копирования]] (shallow copy), глубокое копирование рекурсивно копирует все вложенные объекты, создавая полностью независимую структуру данных.

---
## Когда использовать


Глубокое копирование нужно использовать, если:

- У вас есть вложенные структуры данных (например, список словарей, словарь списков и т.п.).

- Вы хотите, чтобы изменения в копии никак не повлияли на оригинальный объект.
---

  

## Модуль `copy`

  

В Python для копирования объектов используется модуль `copy`:

  

```python

import copy

  

copy.copy(obj)       # Поверхностная копия

copy.deepcopy(obj)   # Глубокая копия
```


```python
import copy

original = [[1, 2], [3, 4]]
shallow = copy.copy(original)
deep = copy.deepcopy(original)

# Изменим вложенный элемент
original[0][0] = 99

print(original)  # [[99, 2], [3, 4]]
print(shallow)   # [[99, 2], [3, 4]]  — изменилось
print(deep)      # [[1, 2], [3, 4]]   — не изменилось

```

## Важные замечания


- deepcopy [[Рекурсия|рекурсивно]] копирует все вложенные объекты.
- Использование deepcopy может быть затратным по времени и памяти на больших структурах.
- Некоторые объекты не поддерживают корректное глубокое копирование (например, сокеты, потоки, функции).

## Дополнительно

Вы можете переопределить метод [[__deepcopy__]] в своём классе, если нужно контролировать процесс копирования вручную:

```python
class MyClass:
    def __init__(self, data):
        self.data = data

    def __deepcopy__(self, memo):
        # Пример ручного копирования
        copied = MyClass(copy.deepcopy(self.data, memo))
        return copied
```
