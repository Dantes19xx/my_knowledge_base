Массивы и связанные списки — это базовые структуры данных, предназначенные для хранения коллекций элементов. Они различаются по организации в памяти, доступу к элементам и эффективности выполнения операций.

---

## Сравнительная таблица

| Операция            | Массив (Array) | Связанный список (Linked List) |
|---------------------|----------------|--------------------------------|
| Доступ по индексу   | O(1)           | O(n)                           |
| Вставка в начало    | O(n)           | O(1)                           |
| Вставка в конец     | O(1)*          | O(1) для односвязного с хвостом|
| Вставка в середину  | O(n)           | O(n)                           |
| Удаление по индексу | O(n)           | O(n)                           |
| Поиск по значению   | O(n)           | O(n)                           |

\* O(1) при наличии заранее зарезервированного пространства (динамический массив, как в Python `list`)

---

## Массив (Array)

### Описание

- Элементы хранятся **в непрерывной области памяти**
- Доступ к элементу осуществляется **по индексу**
- В Python реализован как `list`, но это **динамический массив**

### Пример

```python
arr = [10, 20, 30, 40]
print(arr[2])  # O(1) — доступ по индексу
arr.append(50)  # O(1)* — добавление в конец
arr.insert(1, 15)  # O(n) — вставка в середину
```

### Плюсы

- Быстрый доступ по индексу: `O(1)`
    
- Компактное хранение
    
- Хорошо работает с кэшами процессора
    

### Минусы

- Дорогие вставки/удаления в середине: `O(n)`
    
- Фиксированный размер в классических языках (не в Python)


---

## Связанный список (Linked List)

### Описание

- Каждый элемент (узел) содержит **значение и ссылку на следующий**
    
- Память не обязательно смежная
    
- Бывают: односвязные, двусвязные, циклические

В каждом элементе связанного списка выделяется некоторый объем памяти для хранения адреса следующего элемента этого списка (указатель).

При удалении, указатель смещается на предыдущий от удаляемого элемента.

## Пример (односвязный список на Python)

```python
class Node:
    def __init__(self, val):
        self.val = val
        self.next = None

head = Node(10)
head.next = Node(20)
head.next.next = Node(30)
```


### Плюсы

- Лёгкость вставки и удаления в начало: `O(1)`
    
- Не требует смежной памяти
    
- Хорош при реализации очередей, стеков, списков с частыми вставками
    

### Минусы

- Медленный доступ по индексу: `O(n)`
    
- Требует дополнительной памяти на ссылки
    
- Хуже кэшируется, чем массив


---
## Когда использовать

|Условие|Структура|
|---|---|
|Частый доступ по индексу|Массив|
|Частые вставки и удаления в начале|Связанный список|
|Неизвестен размер заранее|Связанный список|
|Необходима компактность и предсказуемость|Массив|

---

## Вариации связанных списков

- **Односвязный список**: только ссылка на следующий элемент
    
- **Двусвязный список**: ссылки на следующий и предыдущий
    
- **Циклический список**: последний элемент указывает на первый
    

---

## Итоги

- **Массивы** хороши для быстрого доступа, хуже для модификаций.
    
- **Связанные списки** — наоборот: дешевы при вставках, но медленны при доступе по индексу.
    
- Выбор зависит от конкретной задачи и частоты операций.

Массивы используются часто, поскольку имеют множество преимуществ перед связанными списками. Во-первых, их проще читать. Во-вторых, массивы подерживают произвольный доступ. Всего существуют два вида доступа: произвольный и последовательный. При последовательном доступе элементы читаются по одному, начиная с первого. Связанные списки поддерживают только последовательный доступ. Если вы захотите прочитать 10-й элемент связанного списка, вам придется прочитать первые 9 элементов и перейти по ссылкам к 10-му элементу. Многие реальные ситуации требуют произвольного доступа, поэтому массивы часто применяются на практике. Однако даже безотносительно произвольного доступа массивы работают быстрее, поскольку могут использовать [[Почему массивы быстрее благодаря кэшированию|кэширование]].
