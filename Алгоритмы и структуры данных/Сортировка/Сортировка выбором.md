### Суть алгоритма

Сортировка выбором — простой алгоритм сортировки, который работает следующим образом:

1. Находит **минимальный элемент** из неотсортированной части массива.
    
2. **Меняет его местами** с первым элементом этой части.
    
3. Повторяет процесс для оставшихся элементов.

```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

# Пример
array = [64, 25, 12, 22, 11]
sorted_array = selection_sort(array)
print(sorted_array)  # [11, 12, 22, 25, 64]
```


---

### Характеристики

|Критерий|Значение|
|---|---|
|Временная сложность|O(n²)|
|Пространственная|O(1)|
|Стабильность|Нет (если не модифицировать)|
|Подходит для|Маленьких массивов|

---

### Примечания

- Алгоритм простой, но неэффективен на больших данных.
    
- Хорош для **обучения** и понимания базовой логики сортировки.
    
- Работает **на месте**, не требует дополнительной памяти.
