
## Идея
Алгоритмы позволяют находить **следующую** (большую) или **предыдущую** (меньшую) перестановку числа/массива в лексикографическом порядке.  

### Общие шаги
1. Найти **pivot** — первую позицию справа, где порядок нарушается:
   - для Next: `s[i] < s[i+1]`
   - для Previous: `s[i] > s[i+1]`
2. Найти в хвосте справа **кандидата** для замены:
   - для Next: минимальный элемент, который больше `s[pivot]`
   - для Previous: максимальный элемент, который меньше `s[pivot]`
3. Поменять pivot и кандидата местами.
4. Упорядочить хвост:
   - для Next: по возрастанию
   - для Previous: по убыванию

---

## Пример: Next Permutation
Число `12543`

1. Pivot: `2` (т.к. `2 < 5`)  
2. Кандидат: `3` (наименьшее > `2`)  
3. Меняем → `13542`  
4. Хвост по возрастанию → `13245`  

**Результат:** `13245`

---

## Пример: Previous Permutation
Число `5617`

1. Pivot: `6` (т.к. `6 > 1`)  
2. Кандидат: `5` (наибольшее < `6` справа)  
3. Меняем → `5617` → `5167`  
4. Хвост по убыванию → `5176`  

**Результат:** `5176`

---

## Применение
- Генерация всех перестановок в нужном порядке  
- Поиск ближайшего большего/меньшего числа из цифр  
- В задачах на комбинаторику и оптимизацию
