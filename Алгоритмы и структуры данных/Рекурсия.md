
Рекурсия — это метод решения задачи, при котором функция вызывает саму себя. Это мощный инструмент, который позволяет решать задачи простым и элегантным способом, особенно когда проблема может быть разделена на подобные подзадачи.

## Основные понятия:

1. **Рекурсивная функция**:
   Функция, которая вызывает сама себя, обычно с модификацией параметров, чтобы постепенно приблизиться к базовому случаю.

2. **Базовый случай**:
   Условие, при котором рекурсия прекращается. Без базового случая рекурсия может привести к бесконечному циклу и ошибке переполнения стека.

3. **Рекурсивный случай**:
   Часть алгоритма, которая вызывает саму себя для решения меньшей подзадачи. Постепенно каждый рекурсивный вызов приближает решение к базовому случаю.

## Пример рекурсивной функции:

### Факториал числа

Один из самых распространенных примеров рекурсии — вычисление факториала числа.

**Формула для вычисления факториала**:

```
n! = n * (n-1) * (n-2) * ... * 1
```

```python
def factorial(n):
    if n == 0:
        return 1  # Базовый случай
    else:
        return n * factorial(n - 1)  # Рекурсивный случай

print(factorial(5))  # Вывод: 120
```


---
### Стек вызовов при рекурсии

При каждом рекурсивном вызове информация о текущем состоянии функции (включая параметры) добавляется в [[Стек вызовов|стек вызовов]]. В случае с факториалом для `factorial(5)` стек вызовов будет следующим:

```
factorial(5) -> factorial(4) -> factorial(3) -> factorial(2) -> factorial(1) -> factorial(0)
```

Когда базовый случай (`factorial(0)`) возвращает результат, стек начинает раскрываться (выход из рекурсии) и возвращаются результаты всех предыдущих вызовов.

## Преимущества рекурсии:

- **Чистота и краткость кода**: Рекурсия часто позволяет решить сложные задачи, используя меньше строк кода.
    
- **Решение проблем с делением на подзадачи**: Рекурсия идеально подходит для задач, которые можно разбить на более простые подзадачи (например, задачи с деревьями или графами).
    

## Недостатки рекурсии:

- **Переполнение стека**: Если рекурсия слишком глубокая (например, из-за отсутствия корректного базового случая), это может привести к ошибке переполнения стека.
    
- **Меньшая эффективность**: В некоторых случаях рекурсивный алгоритм может быть менее эффективным по времени и памяти, чем итеративное решение.
    

## Применение рекурсии:

- **Поиск в глубину (DFS)** в графах и деревьях.
    
- **Обход деревьев**: например, в задачах по обработке файловой системы.
    
- **Алгоритмы сортировки**, такие как [[Быстрая сортировка|QuickSort]] и MergeSort.
    
- **Решение задач, основанных на разбиении** (например, задача о разбиении чисел).


---
## Важные моменты:

- **Рекурсия может быть заменена итерацией**: В некоторых случаях рекурсивный алгоритм можно преобразовать в итеративный, чтобы избежать проблем с переполнением стека.
    
- **Оптимизация хвостовой рекурсии**: Некоторые языки программирования поддерживают оптимизацию хвостовой рекурсии, при которой рекурсивный вызов не приводит к добавлению


---
## Заключение

Рекурсия — это мощный инструмент для решения задач, когда задача может быть разбита на меньшие подзадачи. Несмотря на свои преимущества, рекурсия требует внимательного подхода для избегания переполнения стека и не всегда является самой эффективной в плане производительности.
