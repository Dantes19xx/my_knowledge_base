Способ сортировки является [[Рекурсия|рекурсивным]].

```python
def quick_sort(arr: list[int]) -> list[int]:  
    if len(arr) < 2:  
        return arr  
  
    pivot: int = arr[0]  
  
    less: list[int] = [i for i in arr[1:] if i <= pivot]  
    greater: list[int] = [i for i in arr[1:] if i > pivot]  
  
    return quick_sort(less) + [pivot] + quick_sort(greater)
```
