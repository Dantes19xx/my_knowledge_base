**Хэш-функция** — это детерминированная функция, которая принимает вход (например, строку или число) и возвращает фиксированной длины числовое значение (обычно целое), называемое **хэшом** или **хэш-кодом**.

---

## Основные свойства хорошей хэш-функции

|Свойство|Описание|
|---|---|
|**Детерминированность**|Один и тот же ввод всегда даёт одинаковый результат|
|**Быстродействие**|Быстро вычисляется|
|**Равномерное распределение**|Распределяет значения равномерно по диапазону хэшей|
|**Минимум коллизий**|Разные ключи редко дают одинаковый хэш|
|**Необратимость** _(для крипто-хэшей)_|Невозможно восстановить исходные данные по хэшу|

---

## Где используется

- **[[Хэш-таблицы]]** — преобразуют ключ в индекс массива
    
- **Контроль целостности** — например, `MD5`, `SHA256`
    
- **Хеширование паролей**
    
- **Поиск и сравнение данных**
    
- **Базы данных, компиляторы, кеши**


---

## Пример хэш-функции (упрощённой)

```python
def simple_hash(s: str, size: int) -> int:
    hash_code = 0
    for char in s:
        hash_code += ord(char)
    return hash_code % size

print(simple_hash("Alice", 10))  # Например, вернёт индекс от 0 до 9
```
