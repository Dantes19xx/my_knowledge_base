Коллизия — это ситуация, когда два разных входа дают одинаковый хэш-индекс.

### Пример

```
simple_hash("abc", 10) == simple_hash("xyz", 10)
```

### Способы разрешения коллизий

- **Цепочки (chaining)**: в ячейке массива хранится список значений
    
- **Открытая адресация**: при коллизии ищется следующая свободная ячейка
    
    - Линейный пробинг
        
    - Квадратичный пробинг
        
    - Двойное хэширование
