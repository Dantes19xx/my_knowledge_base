# Граф (Graph) в контексте алгоритмов

## Определение

**Граф** — это абстрактная структура данных, которая состоит из **вершин (nodes, vertices)** и **рёбер (edges)**, соединяющих пары вершин.

Обозначается как:  
**G = (V, E)**  
где:
- `V` — множество вершин  
- `E` — множество рёбер (пары вершин)

## Типы графов

| Тип                                               | Описание                                                                           |
| ------------------------------------------------- | ---------------------------------------------------------------------------------- |
| **[[Ориентированный граф (направленный)]]**       | Рёбра имеют направление (от одной вершины к другой).                               |
| **[[Неориентированный граф\|Неориентированный]]** | Рёбра не имеют направления (двусторонняя связь).                                   |
| **[[Взвешенный граф]]**                           | Каждому ребру присвоено числовое значение (вес).                                   |
| **[[Невзвешенный граф]]**                         | Все рёбра равнозначны.                                                             |
| **[[Циклический граф]]**                          | Содержит хотя бы один цикл (путь, начинающийся и заканчивающийся в одной вершине). |
| **[[Ациклический граф\|Ациклический (DAG)]]**     | Не содержит циклов.                                                                |
| **[[Связный граф]]**                              | Из любой вершины можно добраться до любой другой.                                  |
| **[[Несвязный граф]]**                            | Есть изолированные вершины или подграфы.                                           |

## Представление графа в алгоритмах

| Метод                                    | Описание                                                  | Пример                        |
| ---------------------------------------- | --------------------------------------------------------- | ----------------------------- |
| **Список смежности (adjacency list)**    | Для каждой вершины хранится список соседей.               | `{A: [B, C], B: [C], C: [A]}` |
| **Матрица смежности (adjacency matrix)** | Двумерный массив `n x n`, где `1` означает наличие ребра. | `[[0,1,1],[0,0,1],[1,0,0]]`   |
| **Список рёбер (edge list)**             | Перечисление всех рёбер.                                  | `[(A, B), (A, C), (B, C)]`    |

## Основные алгоритмы, работающие с графами

- **Поиск в глубину (DFS)**
- **Поиск в ширину (BFS)**
- **Алгоритм Дейкстры** (поиск кратчайшего пути)
- **Алгоритм Беллмана-Форда**
- **Алгоритм Крускала и Прима** (построение минимального остовного дерева)
- **Топологическая сортировка** (для DAG)
- **Алгоритм Флойда-Уоршелла**

## Применение графов

- Сетевые маршруты (интернет, дороги)
- Социальные сети (узлы — пользователи, рёбра — связи)
- Расписание и планирование задач (DAG)
- Навигация, GPS, игры, и многое другое

---

> 📌 **Заметка:** В алгоритмах важно выбирать подходящее представление графа (список смежности, матрица), так как это влияет на сложность операций и эффективность алгоритмов.
