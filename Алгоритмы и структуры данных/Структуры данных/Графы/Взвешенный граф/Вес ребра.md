Вес ребра в графе нужен для **оценки стоимости перехода между вершинами**. Это позволяет не просто учитывать наличие пути, а **сравнивать альтернативные маршруты** и выбирать оптимальные.


---

### Основные цели использования веса рёбер:

| Назначение веса                   | Примеры задач                                                                             |
| --------------------------------- | ----------------------------------------------------------------------------------------- |
| **Расстояние**                    | Построение кратчайшего маршрута на карте (навигация, логистика)                           |
| **Время**                         | Планирование графика: сколько времени занимает переход от задачи к задаче                 |
| **Стоимость**                     | Определение наименьших затрат (например, доставка товара с минимальной платой)            |
| **Пропускная способность**        | Поиск оптимального маршрута в сетях передачи данных                                       |
| **Надёжность / риск / приоритет** | Учет риска при переходе (например, в системах безопасности или играх)                     |
| **Плотность связи**               | В социальных сетях: сила связи между пользователями (насколько часто они взаимодействуют) |

### Почему это важно в алгоритмах

Алгоритмы, такие как **Дейкстра, Беллман-Форд, Прим, Крускал**, используют веса, чтобы:

- Выбирать **оптимальный путь**
    
- Исключать **дорогие переходы**
    
- Строить **минимальное остовное дерево** (набор связей с минимальной суммой весов)


---

### 🔍 Пример

Если у тебя есть такой граф:

`A → B (5) A → C (1) C → B (1)`

- Без учёта весов путь `A → B` напрямую кажется хорошим.
    
- Но с весами лучший путь: `A → C → B` с общей стоимостью `1 + 1 = 2`.


### Вывод

> **Вес рёбер добавляет смысл и метрику в связи между объектами.** Это превращает граф из просто "карты связей" в инструмент **анализа, оптимизации и принятия решений**.
