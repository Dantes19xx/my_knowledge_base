# Ориентированный граф (Directed Graph, Digraph)

## Определение

**Ориентированный граф (направленный граф)** — это граф, в котором рёбра имеют направление.  
Каждое ребро задаётся упорядоченной парой вершин:  
`(u → v)` — означает, что существует путь от вершины `u` к вершине `v`, но не обязательно в обратную сторону.

Обозначение:  
**G = (V, E)**, где `E` — множество упорядоченных пар.

## Пример

A → B  
↓  
C → D


Список рёбер:  
`[(A, B), (A, C), (C, D)]`

## Свойства

- Необязательно симметричен: `(u → v)` ≠ `(v → u)`
- Может содержать **петли**: `(u → u)`
- Может содержать **циклы**
- Может быть **ациклическим** — такой граф называют **DAG (Directed Acyclic Graph)**


## Алгоритмы для ориентированных графов

- **DFS / BFS** — для поиска путей, проверки достижимости
- **Алгоритм Коса­раю / Тарьяна** — поиск сильных компонент связности
- **Топологическая сортировка** — сортировка узлов DAG по зависимостям
- **Дейкстра / Беллман-Форд** — поиск кратчайших путей

## Примеры использования

- **Граф зависимостей** между задачами (построение порядка выполнения)
- **Навигация и карты**, где движение возможно только в одну сторону (например, односторонние улицы)
- **Вычислительные графы** в компиляторах, планировщиках, потоках данных
- **Сети переходов**, такие как графы состояний в автоматах

---

> 💡 **Важно:** Направленность рёбер влияет на достижимость, поиск циклов и стратегию обхода графа.
