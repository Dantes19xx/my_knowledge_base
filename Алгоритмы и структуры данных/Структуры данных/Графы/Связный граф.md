#структуры_данных 

## Определение

**Связный граф** — это граф, в котором **любая вершина достижима из любой другой**.

Тип зависит от направления рёбер:

- В **неориентированном графе**: граф **связный**, если между **каждой парой вершин** существует путь.
- В **ориентированном графе**:
  - **Сильно связный (strongly connected)** — если для **каждой пары вершин (u, v)** существует **путь от u к v и от v к u**
  - **Слабо связный (weakly connected)** — если рёбра рассматривать как неориентированные, и тогда граф становится связным

## Типы связности

| Тип                                     | Описание                                                     |
| --------------------------------------- | ------------------------------------------------------------ |
| **Связный (connected)**                 | Неориентированный граф, где каждая вершина достижима         |
| **[[Несвязный граф]] (disconnected)**   | Есть хотя бы одна пара вершин без пути                       |
| **Сильно связный (strongly connected)** | Ориентированный граф: путь `u → v` и `v → u` для всех пар    |
| **Слабо связный (weakly connected)**    | Если игнорировать направление рёбер, граф становится связным |

## Обнаружение связности

| Метод                    | Подходит для                                  | Описание                           |
| ------------------------ | --------------------------------------------- | ---------------------------------- |
| **DFS / BFS**            | Неориентированные и ориентированные графы     | Проверка достижимости всех вершин  |
| **Алгоритм Коса­раю**    | Ориентированный граф                          | Выделение сильно связных компонент |
| **Компоненты связности** | Для подсчёта и анализа изолированных участков |                                    |

## Применение

- Проверка целостности сетей (интернет, электричество)
- Социальные сети (есть ли "островки" пользователей)
- Построение кластеров в графах
- Анализ достижимости в логистике и маршрутах

## Визуальный тест

Для неориентированного графа:
- Начни DFS/BFS с любой вершины
- Если **все вершины были посещены**, граф связный

---

> 💡 **Замечание:** В реальных задачах часто анализируют **компоненты связности**, особенно в больших графах (социальные сети, блокчейны и т.д.).
