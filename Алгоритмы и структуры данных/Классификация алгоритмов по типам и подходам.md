Алгоритмы — это основа программирования и разработки ПО.

## **Классификация алгоритмов по типам и подходам**

| Категория                                                                     | Описание и примеры                                                                                                               |
| ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **Сортировка**                                                                | Упорядочивание данных. Примеры: Bubble Sort, Merge Sort, [[Быстрая сортировка\|Quick Sort]], Heap Sort.                          |
| **Поиск**                                                                     | Нахождение элемента в структуре данных. Примеры: [[Бинарный поиск]], Линейный поиск.                                             |
| **Жадные алгоритмы**                                                          | Принимают локально оптимальное решение в надежде на глобальный результат. Примеры: Задача о рюкзаке (Greedy), покрытие отрезков. |
| **Динамическое программирование (DP)**                                        | Разбивает задачу на подзадачи и запоминает решения. Примеры: Фибоначчи, Задача о рюкзаке (DP), минимальный путь.                 |
| **Разделяй и властвуй**                                                       | Деление задачи на части. Примеры: Merge Sort, Quick Sort, Binary Search.                                                         |
| **Алгоритмы на графах**                                                       | Работа с узлами и рёбрами. Примеры: BFS, DFS, Dijkstra, A*.                                                                      |
| **Поиск в глубину / ширину (DFS/[[Пример реализации поиска в ширину\|BFS]])** | Обход деревьев и графов. Используются в графах, лабиринтах, деревьях.                                                            |
| **Деревья и структуры поиска**                                                | Например, бинарные деревья поиска (BST), сбалансированные деревья (AVL, Red-Black).                                              |
| **Алгоритмы на строках**                                                      | Поиск подстроки, сравнение строк. Примеры: KMP, Rabin-Karp, Z-алгоритм.                                                          |
| **Алгоритмы на числах**                                                       | Евклид (НОД), решето Эратосфена, быстрое возведение в степень.                                                                   |
| **Алгоритмы на множестве / хэшах**                                            | Быстрый поиск / вставка. Примеры: HashMap, Set.                                                                                  |

---

## С чего начать изучение

1. **Базовые темы:**
    
    - Сортировка (Bubble, Merge, Quick)
        
    - Бинарный поиск
        
    - DFS и BFS
        
2. **Далее:**
    
    - Жадные алгоритмы
        
    - Динамическое программирование
        
    - Алгоритмы на графах (Dijkstra, Kruskal, Union-Find)
        
    - Задачи на строки (поиск подстроки, палиндромы)
        
3. **Углубление:**
    
    - Теория чисел, оптимизация, комбинаторика
        
    - Алгоритмы для собеседований (LeetCode, Codeforces, AtCoder и др.)

## Инструменты для практики

- **Платформы с задачами:** LeetCode, HackerRank, Codeforces, AtCoder, Stepik
    
- **Книга:** «Грокаем алгоритмы» (Aditya Bhargava) — хорошее введение
    
- **Python-библиотеки:** `heapq`, `collections`, `itertools` — часто помогают в решении
