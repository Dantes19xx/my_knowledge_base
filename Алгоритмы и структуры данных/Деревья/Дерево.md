
#структуры_данных 
### Объяснение:

**Структура данных** — это способ организации и хранения данных, чтобы эффективно выполнять операции над ними (например, поиск, вставку, удаление).
Дерево является разновидностью графа, к нему можно применить алгоритм, работающий с графом.
При поске в дереве, не нужно проверять что узел проверялся или нет, потому что у каждого узла может быть только один родительский узел.
*В дереве не бывает циклов.*


**Дерево** — это **иерархическая структура данных**, в которой:

- Каждый элемент называется **узлом (node)**.
    
- Есть **один корень (root)** — главный узел.
    
- У каждого узла могут быть **дочерние узлы (children)**.
    
- Узлы без потомков называются **листьями (leaves)**.
    
- Связи между узлами называются **рёбрами (edges)**.


    

---

### Примеры деревьев как структур данных:

| Тип дерева                                | Особенности                                                               |
| ----------------------------------------- | ------------------------------------------------------------------------- |
| **[[Бинарные деревья\|Бинарное дерево]]** | У каждого узла не более двух потомков.                                    |
| **BST (Binary Search Tree)**              | Упорядоченное бинарное дерево: левый подузел < родитель < правый подузел. |
| **AVL, Red-Black**                        | Самобалансирующиеся деревья.                                              |
| **Heap (куча)**                           | Поддерживает свойства кучи (максимума или минимума).                      |
| **Trie (бор)**                            | Часто используется для хранения строк, например, в словарях.              |
| **B-дерево**                              | Используется в базах данных и файловых системах.                          |

---

### Дерево и алгоритмы

Хотя дерево — это **структура данных**, с ним связано множество **алгоритмов**, таких как:

- Поиск (DFS, [[Поиск в ширину|BFS]])
    
- Балансировка (в AVL, Red-Black)
    
- Построение и обход (прямой, симметричный, обратный)
    
- Поиск наименьшего общего предка
    
- Построение префиксных деревьев (Trie)
