**Пространственная сложность** — это количество памяти, которое алгоритм использует в зависимости от размера входных данных.

### Основные категории:

|Нотация|Значение|
|---|---|
|`O(1)`|Алгоритм не требует дополнительной памяти|
|`O(n)`|Требуется память пропорционально входу|
|`O(n²)`|Используется двумерная структура (матрица)|

---
## Пример: создание копии списка

```python
def copy_list(arr):
    return arr[:]
```

- Временная сложность: `O(n)`
    
- Пространственная сложность: `O(n)` — создаётся новый список того же размера.


---
## Пример: [[Рекурсия]]

```python
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)
```

- Временная сложность: `O(n)`
    
- Пространственная сложность: `O(n)` — каждый вызов хранится в [[Стек вызовов|стеке вызовов]].


---
## Что важно помнить

- `O(...)` показывает **тренд роста**, а не точные значения.
    
- Используется для **анализа и сравнения алгоритмов**.
    
- Оценивается **и время**, и **память**, в зависимости от задачи.
    

---

## Связанные понятия

- **Ω (Омега)** — нижняя граница сложности.
    
- **Θ (Тета)** — точная граница (и верхняя, и нижняя).
    
- **Временная сложность** — сколько шагов нужно выполнить.
