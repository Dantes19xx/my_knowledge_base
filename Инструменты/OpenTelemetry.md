
## Что это

**OpenTelemetry (OTel)** — это открытый стандарт и набор инструментов для сбора:

- 🔁 трейсов (Traces),
- 📊 метрик (Metrics),
- 📋 логов (Logs)

из приложений. Это совместный проект CNCF, пришедший на замену OpenTracing и OpenCensus.

---

## Возможности

- Поддержка многих языков (Python, Go, Java, JS и др.).
- Интеграции с популярными фреймворками (Flask, FastAPI, Django и др.).
- Экспорт в Jaeger, Prometheus, Zipkin, Datadog, Tempo и др.
- Автоматическая и ручная инструментализация.

---

## Архитектура

| Компонент       | Назначение                                                  |
| --------------- | ----------------------------------------------------------- |
| SDK             | Библиотека для интеграции в приложение.                     |
| Instrumentation | Автоматическое добавление трейсинга в фреймворки.           |
| Collector       | Отдельный сервис для обработки и экспорта данных.           |
| Exporter        | Отправка в систему наблюдения ([[Jaeger]], [[Prometheus]]). |

---

## Типы данных

1. **Traces** — отображают путь запроса по системе.
2. **Metrics** — численные значения (ошибки, время, нагрузка).
3. **Logs** — текстовые сообщения и ошибки.

---

## Пример (Python + FastAPI)

```bash
pip install opentelemetry-api \
            opentelemetry-sdk \
            opentelemetry-exporter-jaeger \
            opentelemetry-instrumentation-fastapi

```
