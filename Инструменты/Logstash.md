
**Logstash** — это инструмент с открытым исходным кодом для сбора, обработки и трансформации данных. Он является частью **[[ELK]] Stack** ([[Elasticsearch]], Logstash, [[Kibana]]) и обычно используется для сбора логов и других данных из различных источников перед их отправкой в **Elasticsearch**. 

---

## Основные возможности

- **Сбор данных** — Logstash может собирать данные из множества источников, таких как файлы, базы данных, очереди сообщений и другие.
- **Обработка данных** — данные можно фильтровать, преобразовывать и обогащать с помощью плагинов.
- **Форматирование данных** — возможность изменения структуры данных перед отправкой в Elasticsearch или другие хранилища.
- **Масштабируемость** — Logstash может работать в распределённых системах и масштабироваться в зависимости от объёма данных.

---

## Как работает Logstash

1. **Входные данные (Input)** — Logstash получает данные из различных источников: файлов, баз данных, API и других.
2. **Обработка (Filter)** — с помощью плагинов данные могут быть преобразованы, отфильтрованы или обогащены.
3. **Выходные данные (Output)** — обработанные данные могут быть отправлены в различные хранилища, включая **Elasticsearch**, базы данных или даже другие системы.

---

## Структура конфигурации

Конфигурация Logstash состоит из трёх частей:

1. **Input** — источники данных:
   - Пример: `file`, `stdin`, `beats`, `http`.
   
2. **Filter** — фильтры для обработки данных:
   - Пример: `grok` для парсинга текста, `mutate` для изменения полей.

3. **Output** — куда отправлять обработанные данные:
   - Пример: `elasticsearch`, `stdout`, `file`.

Пример конфигурации Logstash:

```plaintext
input {
  file {
    path => "/var/log/*.log"
    start_position => "beginning"
  }
}

filter {
  grok {
    match => { "message" => "%{COMBINEDAPACHELOG}" }
  }
}

output {
  elasticsearch {
    hosts => ["http://localhost:9200"]
    index => "logs-%{+YYYY.MM.dd}"
  }
}
```

## Применение

- **Обработка логов** — часто используется для сбора логов с различных серверов и их отправки в Elasticsearch для дальнейшего анализа.
    
- **Интеграция с другими инструментами** — может работать в связке с **Beats**, **Kafka**, **Fluentd** и другими инструментами для сбора данных.
    
- **Преобразование данных** — позволяет изменять или обогащать данные перед отправкой в хранилище.

### Преимущества:

- Мощная обработка данных с помощью плагинов.
    
- Поддержка множества источников данных.
    
- Гибкость в настройке.
    

### Недостатки:

- Может потреблять много ресурсов при работе с большими объёмами данных.
    
- Требует настройки и оптимизации для работы с высокими нагрузками.
