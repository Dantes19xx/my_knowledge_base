# Jaeger — система распределённого трейсинга

## Что такое Jaeger

**Jaeger** — это open-source инструмент от Uber для распределённого трейсинга в микросервисной архитектуре. Позволяет отслеживать, как запрос проходит через разные сервисы.

---

## Возможности

- Визуализация пути запроса.
- Метки времени и задержки на каждом шаге.
- Поиск узких мест.
- Интеграция с [[OpenTelemetry]].
- Графический интерфейс.

---

## Архитектура

| Компонент | Назначение                                       |     |
| --------- | ------------------------------------------------ | --- |
| Agent     | Получает трейсы от приложений.                   |     |
| Collector | Обрабатывает и передаёт в хранилище.             |     |
| Storage   | [[Elasticsearch]], Cassandra, Badger, etc.       |     |
| Query     | Интерфейс для запросов к хранилищу.              |     |
| UI        | Веб-интерфейс для визуального просмотра трейсов. |     |

---

## Как это работает

1. Приложение генерирует трейс через SDK (например, OpenTelemetry).
2. Отправляет данные в Agent.
3. Agent передаёт данные в Collector.
4. Collector сохраняет их.
5. UI позволяет посмотреть детали.
