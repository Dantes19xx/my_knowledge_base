## Что это
**Alembic** — это инструмент для управления миграциями базы данных в проектах на Python.  
Разработан как часть экосистемы **SQLAlchemy**.  

Его задача: отслеживать изменения в моделях и аккуратно применять их к реальной базе данных.

---

## Зачем нужен
- Позволяет изменять структуру БД без потери данных.  
- Хранит историю миграций (как Git для базы данных).  
- Работает с разными СУБД (PostgreSQL, MySQL, SQLite и др.).  
- Удобен для командной разработки (каждый разработчик может применить одинаковые миграции у себя).  

---

## Основные понятия

- **Migration script** — файл, описывающий изменения (например, добавление таблицы или столбца).  
- **Heads / Revisions** — версии схемы базы данных.  
- **Upgrade/Downgrade** — применение или откат изменений.  

---

## Основные команды Alembic

```bash
alembic init migrations         # создать папку для миграций
alembic revision -m "комментарий"  # создать новый файл миграции
alembic upgrade head            # применить все миграции
alembic downgrade -1            # откатить одну миграцию назад
alembic history                 # показать историю миграций
```


---

## Пример миграции

```python
def upgrade():
    op.add_column("user", sa.Column("email", sa.String(120), nullable=True))

def downgrade():
    op.drop_column("user", "email")
```

👉 `upgrade` — выполняется при `alembic upgrade`.  
👉 `downgrade` — выполняется при `alembic downgrade`.

---

## Alembic и Flask-Migrate

- **Alembic** — это ядро для миграций.
    
- **[[Flask-Migrate]]** — обёртка над Alembic для удобной интеграции с Flask.
    
- То есть все команды `flask db ...` внутри используют Alembic.
    

---

## Итог

- Alembic = система версионирования базы данных.
    
- Позволяет безопасно изменять схему и хранить историю изменений.
    
- В связке с Flask используется через **Flask-Migrate**.
