Для реализации [[RED]]-метода может использоваться **Prometheus**. Этот инструмент позволяет собирать, хранить и анализировать метрики, визуализировать и создавать предупреждения.

✏️ **Prometheus** — это система мониторинга и оповещения с открытым исходным кодом, созданная на языке программирования Golang. Проект был разработан компанией SoundCloud, но сейчас его поддерживает независимое сообщество разработчиков.

### Кратко о главном:

| Характеристика      | Описание                                                                       |
| ------------------- | ------------------------------------------------------------------------------ |
| **Назначение**      | Сбор и хранение метрик в виде временных рядов.                                 |
| **Метод сбора**     | _Pull_-подход — Prometheus сам опрашивает цели (экспортеры).                   |
| **Хранение данных** | Локальная база данных с собственным форматом хранения.                         |
| **Язык запросов**   | PromQL — язык для выборки и агрегации метрик.                                  |
| **Визуализация**    | Встроенный веб-интерфейс + интеграция с [[Grafana]].                           |
| **Оповещения**      | Alertmanager — отдельный компонент для обработки алертов.                      |
| **Расширяемость**   | Через экспортеры (Node Exporter, Blackbox Exporter и др.).                     |
| **Особенности**     | Простая настройка, высокая надёжность, идеален для микросервисов и Kubernetes. |
### Модель «ключ — значение»

Prometheus использует модель данных на основе пар «ключ — значение». Ключ здесь описывает, какую метрику мы измеряем, а значение хранит число, которое отражает измеренную величину за определённый период времени.

Ключ — это сама метрика (к примеру, скорость процессора или объём памяти). Но если нужна дополнительная информация, используются ярлыки. Они помогают добавить детали — можно измерять не просто скорость процессора, а скорость конкретного ядра по определённому IP-адресу.


### Показатели Prometheus

У Prometheus четыре различных типа показателей:

- **Счётчик**  Подсчитывает количество происходящих событий (может только увеличиваться), например общее количество запросов.
- **Индикатор**  Показывает текущее значение переменной X (может меняться со временем), например количество активных запросов.
- **Гистограмма**  Группирует наблюдения в отдельные сегменты, например время ответа на запрос менее одной секунды.
- **Сводка**  Похожа на гистограмму, но показывает, какой процент наблюдений ниже заданного значения.

# Итоги

- **Prometheus** используется для мониторинга, сбора метрик из различных сервисов и приложений и оповещения — алёртинга. Он позволяет отслеживать работу системы в реальном времени, выявлять проблемы и получать уведомления о возможных сбоях.
- **Grafana** — это инструмент визуализации данных, который используется для создания дашбордов (панелей инструментов) с графиками, диаграммами.
