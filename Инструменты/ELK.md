# ELK Stack

**ELK Stack** — это набор инструментов с открытым исходным кодом для сбора, хранения, поиска и анализа логов и других данных в реальном времени. Состоит из трех компонентов:

1. **[[Elasticsearch]]** — поисковая и аналитическая система для хранения и обработки больших объемов данных.
2. **[[Logstash]]** — инструмент для сбора, обработки и трансформации данных, перед их отправкой в Elasticsearch.
3. **[[Kibana]]** — веб-интерфейс для визуализации данных из Elasticsearch, который помогает анализировать логи и метрики.

---

## Основные задачи

- **Сбор и обработка логов** — Logstash собирает логи с различных источников.
- **Хранение и поиск** — Elasticsearch сохраняет и индексирует данные для быстрого поиска.
- **Визуализация** — Kibana предоставляет удобный интерфейс для анализа и визуализации данных.

---

## Применение

- Мониторинг серверов и приложений.
- Анализ логов.
- Поиск по большим объемам данных в реальном времени.
