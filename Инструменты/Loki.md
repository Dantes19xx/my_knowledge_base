# Loki — система логирования от Grafana

## Что такое Loki?
Loki — это система сбора и хранения логов от [[Grafana]] Labs. Вдохновлена [[Prometheus]], но предназначена для логов. Loki не индексирует содержимое логов, а только метки (labels), что делает её быстрой и экономной.

## Особенности
| Особенность             | Описание                                                                 |
|-------------------------|--------------------------------------------------------------------------|
| Без парсинга логов      | Индексируются только метки, не содержимое логов.                        |
| Интеграция с Grafana    | Полноценная визуализация логов.                                          |
| Promtail                | Агент для сбора логов и отправки их в Loki.                              |
| Kubernetes-friendly     | Поддержка меток из Kubernetes (под, неймспейс, контейнер и т.п.).        |
| Масштабируемость        | Горизонтально масштабируется, работает с внешним хранилищем (S3 и др.). |

## Компоненты
- **Loki** — сервер хранения логов.
- **Promtail** — агент сбора логов.
- **Grafana** — визуализация логов.
- **LogCLI** — CLI-интерфейс для работы с Loki.

## Принцип работы
1. Приложение пишет логи (stdout или файл).
2. Promtail считывает логи и добавляет метки.
3. Отправляет данные в Loki.
4. В Grafana можно выполнять запросы по меткам, напр.: `{job="nginx"}`.
