**Контейнер Docker** — это изолированная среда, в которой запускается приложение вместе со всеми его зависимостями. Контейнеры работают поверх операционной системы хоста и используют её ядро, но при этом обеспечивают изоляцию процессов, сети и файловой системы.

Контейнер — это рабочий экземпляр образа Docker. Он создаётся из образа и запускается как отдельный процесс, который не влияет на другие контейнеры или систему в целом.

### Ключевые свойства контейнеров:

- **Изоляция**  
    Контейнеры изолируют приложение и его окружение от других процессов и контейнеров. Это позволяет запускать несколько версий одного приложения на одной машине без конфликтов.
    
- **Повторяемость среды**  
    Контейнеры обеспечивают одинаковое поведение приложения в любой среде: на локальной машине, в тестовой или продакшн-среде. Это снижает вероятность ошибок, связанных с разницей в окружениях.
    
- **Лёгковесность**  
    В отличие от виртуальных машин, контейнеры не содержат полноценной операционной системы. Они используют ядро хоста, что делает их гораздо быстрее при запуске и экономичнее по потреблению ресурсов.
    
- **Непостоянство (ephemeral)**  
    По умолчанию данные внутри контейнера не сохраняются между перезапусками. Для хранения данных используется механизм **volumes** (томов) или внешние хранилища.
    

### Жизненный цикл контейнера:

1. **Создание** — контейнер создаётся из образа, но ещё не запущен.
    
2. **Запуск** — контейнер переходит в активное состояние, выполняет основную задачу.
    
3. **Остановка** — процесс внутри контейнера завершён, контейнер останавливается.
    
4. **Удаление** — контейнер может быть удалён вручную или автоматически, если был запущен с флагом `--rm`.
    

### Основные команды:

```bash
# Создание и запуск контейнера
docker run [опции] <image>

# Список работающих контейнеров
docker ps

# Остановка контейнера
docker stop <container_id>

# Удаление контейнера
docker rm <container_id>

```

### Примеры запуска:

```bash
# Простой запуск контейнера с Nginx
docker run --name webserver -p 8080:80 nginx

# Интеррактивный запуск Ubuntu-контейнера
docker run -it ubuntu bash
```

### Сравнение: контейнеры vs виртуальные машины

|Характеристика|Контейнеры|Виртуальные машины|
|---|---|---|
|Изоляция|Уровень процессов|Полная (включая ОС)|
|Использование ресурсов|Низкое|Высокое|
|Время запуска|Секунды|Минуты|
|Размер|Мегабайты|Гигабайты|
|Ядро ОС|Общее (ядро хоста)|Отдельное|
