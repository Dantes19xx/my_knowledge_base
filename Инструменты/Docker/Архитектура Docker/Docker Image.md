## Что такое Docker Image

Docker Image (образ Docker) — это неизменяемый шаблон, содержащий всё необходимое для запуска контейнера:
- исходный код приложения,
- библиотеки и зависимости,
- настройки окружения,
- инструкции для запуска.

Образ можно сравнить с «снапшотом» файловой системы и конфигурации, из которого создаются экземпляры — контейнеры.

## Ключевые характеристики

| Характеристика | Описание |
|----------------|----------|
| **Неизменяемость** | Образы не изменяются после создания. Все изменения происходят в контейнерах. |
| **Слойность** | Каждый образ состоит из слоёв. Новый слой создаётся при каждом изменении `Dockerfile`. |
| **Кеширование** | Docker кеширует слои, что ускоряет сборку образов при повторных запусках. |
| **Портативность** | Один и тот же образ можно запускать на любом хосте, где установлен Docker. |
