**Docker** — это платформа с открытым исходным кодом, предназначенная для автоматизации упаковки, доставки и запуска приложений в изолированных контейнерах.

---

### Архитектура Docker:

- **Docker** — инструмент для создания, запуска и управления контейнерами, которые обеспечивают изоляцию среды выполнения приложения и его зависимостей.
    
- **[[Контейнер Docker]]** — это лёгкая, изолированная среда, в которой запускается приложение. Он содержит всё необходимое: исполняемый файл, библиотеки, зависимости, конфигурации.
    
- **[[Docker Image]] (образ)** — это неизменяемый шаблон, используемый для создания контейнера. Он включает в себя файловую систему, зависимости и команды запуска.
    
- **Dockerfile** — сценарий, содержащий инструкции по созданию Docker-образа. Каждая инструкция — это отдельный слой образа.
    
- **Docker Engine** — основная среда выполнения, которая управляет созданием образов, запуском контейнеров и их взаимодействием.
    
- **Docker Hub** — публичный (или приватный) реестр, где хранятся и распространяются образы Docker.
