
## Что это

**Elasticsearch** — это распределённая поисковая система с открытым исходным кодом, предназначенная для хранения, поиска и анализа больших объёмов данных.

Является частью Elastic Stack ([[ELK]] Stack) и используется для полнотекстового поиска, анализа данных, логирования и мониторинга.

---

## Основные возможности

- 🔎 Полнотекстовый поиск.
- 🧩 Гибкость в запросах с использованием **Query DSL**.
- ⚙️ Масштабируемость для обработки терабайтов данных.
- ⚡ Поиск и индексирование в реальном времени.
- 📊 Инструменты для аналитики и агрегаций.

---

## Как работает

1. **Индексирование** — данные преобразуются в индексы для поиска.
2. **Документы** — данные представлены в виде JSON-документов.
3. **Шардинг** — данные делятся на части (шарды) для распределения нагрузки.
4. **Репликация** — шардированные данные могут иметь реплики для отказоустойчивости.

---

## Структура данных

| Компонент       | Описание                                       |
|-----------------|------------------------------------------------|
| **Индекс**      | Коллекция документов (аналог базы данных).    |
| **Документ**    | Единица данных в индексе (аналог строки в таблице).|
| **Поле**        | Атрибут документа (аналог столбца в таблице).  |
| **Шард**        | Части индекса, которые могут быть размещены на разных узлах.|
| **Реплика**     | Копия шардов для отказоустойчивости.           |

---

## Применение

1. **Поиск логов** — для анализа логов и мониторинга.
2. **Полнотекстовый поиск** — для реализации поиска на веб-сайтах.
3. **Аналитика** — для анализа данных и создания отчетов.
4. **Хранение и поиск данных** — для хранения как структурированных, так и неструктурированных данных.
