

## Что такое Kibana
Kibana — это инструмент визуализации и аналитики данных для Elasticsearch. Позволяет создавать дашборды, графики, карты, а также выполнять поиск и анализ логов в реальном времени.

## Основные возможности
- **Dashboards** — настраиваемые панели мониторинга
- **Discover** — интерактивный просмотр и фильтрация данных
- **Visualize** — построение графиков и диаграмм
- **Maps** — визуализация геоданных
- **Canvas** — создание кастомных презентаций данных
- **Machine Learning** (в платной версии) — автоматическое обнаружение аномалий
- **Dev Tools** — консоль для запросов к Elasticsearch (Console)
- **Alerts & Actions** — настройка алертов (с версии 7.7+)

## Архитектура
- Kibana работает как web-интерфейс к Elasticsearch
- Не хранит данные, а только отображает их из Elasticsearch
- Может быть частью Elastic Stack (ранее [[ELK]]: [[Elasticsearch]], [[Logstash]], Kibana)

## Основные сценарии использования
| Сценарий                     | Описание |
|-----------------------------|----------|
| Мониторинг приложений       | Анализ логов, производительности, ошибок |
| Безопасность                | Анализ инцидентов, аудит доступа |
| Бизнес-аналитика            | Построение отчетов по данным из Elasticsearch |
| DevOps                      | Мониторинг инфраструктуры и метрик |
