# SIEM (Security Information and Event Management)

## Что такое SIEM

**SIEM** — это система управления событиями информационной безопасности, которая объединяет сбор, хранение, анализ и корреляцию логов и событий безопасности в одной платформе.

Полная расшифровка:  
**SIEM = SIM (Security Information Management) + SEM (Security Event Management)**

---

## Основные функции

| Функция                        | Описание |
|-------------------------------|----------|
| **Сбор логов**                | Получение логов с серверов, сетевых устройств, приложений, антивирусов и т.п. |
| **Централизованное хранилище**| Хранение событий и логов в одном месте |
| **Корреляция событий**        | Связывание разных событий для выявления атак |
| **Оповещения**                | Уведомления об аномалиях и инцидентах |
| **Форензика**                 | Расследование ИБ-инцидентов |
| **Визуализация**              | Дашборды, графики, удобный поиск |
| **Соответствие стандартам**   | Помощь в соблюдении требований (ISO 27001, PCI DSS и др.) |

---

## Пример сценария

1. Пользователь 10 раз ввёл неверный пароль → лог в Active Directory  
2. Через минуту — попытка входа с другого IP  
3. SIEM сопоставляет события, формирует инцидент: возможная brute-force атака  
4. Отправляется уведомление в SOC или ИБ-специалисту

## Когда использовать SIEM

- В компаниях с высоким уровнем требований к информационной безопасности
- Для построения SOC (Security Operations Center)
- При необходимости анализа большого объёма логов
- Для аудита и соответствия стандартам ИБ
