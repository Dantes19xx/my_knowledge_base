#ИБ

✏️ **Active Directory (AD)** — это реализация службы каталогов Microsoft, которая использует и расширяет протокол [[LDAP]].


У этой реализации есть несколько особенностей. Active Directory:

- Использует LDAP как один из протоколов.
- Добавляет много Windows-специфичных функций.
- Имеет свои особенности в именовании и структуре.
- Добавляет дополнительные механизмы безопасности.
- Тесно интегрирована с Windows-инфраструктурой.

### Основные отличия AD от чистого LDAP

Различия с точки зрения именования и структуры проще всего показать так:

![](https://pictures.s3.yandex.net/resources/image_9_1730839628.png)


---

Вот отличия на уровне записей:


```
# Чистый LDAP
dn: uid=john,ou=People,dc=example,dc=com

# Active Directory
dn: CN=John Smith,OU=Users,DC=company,DC=com

# Чистый LDAP
dn: uid=john,ou=People,dc=example,dc=com

# Active Directory
dn: CN=John Smith,OU=Users,DC=company,DC=com 
```

Специфичные атрибуты, которые используются в Active Directory:

```
# AD-специфичные атрибуты
sAMAccountName: jsmith
userPrincipalName: john.smith@company.com
memberOf: CN=Sales,OU=Groups,DC=company,DC=com
userAccountControl: 512 
```


Итак, Active Directory добавляет к LDAP:

- Групповые политики (GPO) — то есть политики, применяемые к группам.
- Интеграцию с Windows.
- Доменные службы как для Windows, так и для остальных систем.
- DNS интеграцию.
- Репликацию с несколькими контроллерами домена.
- Kerberos аутентификацию. Это основной способ аутентификации в AD, и он усиливает безопасность каталога. Чтобы сравнить степень защиты, можете посмотреть, какие способы аутентификации используются в LDAP.

### Дополнительные протоколы AD

Active Directory — это полноценная служба каталогов. Кроме LDAP, она также использует:

- **[[Применение протокола Kerberos|Kerberos]].** Это протокол аутентификации, который обеспечивает безопасный обмен данными между пользователями и серверами. С ним вы познакомились в первом уроке этой темы.
- **DNS.** Active Directory использует DNS для разрешения имён компьютеров, контроллеров домена и других ресурсов в сети. Это позволяет пользователям и службам легко находить объекты в Active Directory и взаимодействовать с ними.
- **NTLM.** Это протокол аутентификации и авторизации, который используется в операционных системах Windows. Он обеспечивает защищённый обмен данными между компьютерами в сети и позволяет пользователям получать доступ к ресурсам на этих компьютерах.
- **MS-RPC.** Это протокол удалённого вызова процедур, который используется в операционных системах Windows. Он позволяет программам на одном компьютере вызывать процедуры на другом компьютере через сеть.
