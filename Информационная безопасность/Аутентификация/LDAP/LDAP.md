# LDAP (Lightweight Directory Access Protocol)

#ИБ

## 📌 Определение
LDAP — это прикладной протокол для доступа к распределённым директориям, содержащим информацию о пользователях, группах, устройствах и т.д. Работает поверх TCP/IP.

## 🔧 Основные особенности
- Протокол клиент-серверной архитектуры
- Используется для хранения и запроса информации в иерархической структуре (деревья, DIT)
- Часто применяется в системах централизованной аутентификации ([[SSO]], Active Directory)

## 🧱 [[Структура LDAP|Структура]] данных
- **DN (Distinguished Name)** — уникальный путь к объекту
- **Entry** — единица хранения (например, пользователь)
- **Attribute** — свойства записи (например, `cn`, `mail`, `uid`)
- **OU (Organizational Unit)** — логическая группа объектов

## 💡 Примеры использования
- Аутентификация пользователей (например, через Active Directory)
- Хранение информации о сотрудниках
- Интеграция с [[Применение протокола Kerberos|Kerberos]], SSO, OAuth-провайдерами

## 🧪 Пример DN

```
dn: uid=jdoe,ou=users,dc=example,dc=com  
cn: John Doe  
mail: jdoe@example.com
```


## 🔐 Безопасность
- LDAP по умолчанию небезопасен (передаёт данные в открытом виде)
- Используйте **LDAPS** (LDAP over SSL/TLS) или StartTLS
