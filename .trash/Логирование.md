# 📚 Сбор логов в приложениях

## 🪵 Что такое логи?

**Логи** — это структурированные или неструктурированные текстовые сообщения, которые приложение записывает в процессе своей работы.

**Цели логирования:**
- Диагностика ошибок
- Аудит доступа
- Анализ поведения пользователей
- Мониторинг бизнес-процессов

---

## 🧱 Типы логов

| Тип логов         | Описание                                      | Примеры                                 |
|-------------------|-----------------------------------------------|------------------------------------------|
| 📦 Приложенческие | Работа бизнес-логики, ошибки, события         | Ошибка в API, создание заказа, вход     |
| ⚙️ Системные      | События ОС, запуск процессов, сетевые события | `journalctl`, `syslog`, запуск демона   |
| 🔐 Безопасностные | Попытки входа, смена прав, доступ к данным    | Неудачные логины, эскалация прав        |
| 🌐 Сетевые        | Подключения, отказ в передаче пакетов         | Логи nginx, iptables, сетевые ошибки    |

## 🔁 Подходы к логированию

### 1. 📜 stdout (12-Factor Style)

**Описание:**  
Приложение пишет логи в `stdout` — стандартный вывод. Предпочтительный способ для контейнеров (Docker, Kubernetes).

**Плюсы:**

- Простота и совместимость с платформами
    
- Лёгкость агрегации логов
    

**Минусы:**

- Требует лог-агента или runtime-среду
    

**Инструменты:**  
Docker logging driver, Fluent Bit, Vector, Filebeat

---

### 2. 📁 Логи в файл

**Описание:**  
Запись логов в файл — традиционный способ.

**Плюсы:**

- Удобно локально
    
- Простая реализация
    

**Минусы:**

- Нужно управлять размером (ротация)
    
- Уязвимость к потере данных в краше
    

**Инструменты:**  
logrotate, Filebeat, Fluent Bit

---

### 3. 📡 Агентский сбор

**Описание:**  
Агенты собирают логи (из stdout или файлов), парсят и отправляют их в хранилище.

**Популярные агенты:**

- **Fluent Bit** — лёгкий, C
    
- **Filebeat** — часть Elastic Stack
    
- **Vector** — быстрый, на Rust
    

**Плюсы:**

- Производительность
    
- Гибкая фильтрация
    

---

### 4. ☁️ Централизованное хранилище

**Описание:**  
Хранение логов в индексируемом формате для поиска и визуализации.

| Система       | Особенности                               |
| ------------- | ----------------------------------------- |
| Elasticsearch | Мощный поиск, часть [[ELK]]               |
| Loki          | Оптимизирован под [[Prometheus]] + лейблы |
| OpenSearch    | Форк Elastic, доступен под open-source    |
| Graylog       | SIEM-функции, масштабируемый UI           |
