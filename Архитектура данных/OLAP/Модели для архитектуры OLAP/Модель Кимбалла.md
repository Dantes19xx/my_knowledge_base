# Модель Кимбалла (Kimball's Approach)

## 📘 Что это

Модель Кимбалла — это подход к построению хранилища данных, предложенный **Ральфом Кимбаллом**. В отличие от [[Модель Инмона|Инмона]], Кимбалл предлагает **строить хранилище "от витрин к центру"**, начиная с потребностей бизнеса.

Хранилище представлено **набором Data Marts (витрин данных)**, объединённых общей **многомерной моделью (звезда / снежинка)**.

---

## 🔑 Основные идеи

- Начинать нужно с **бизнес-задач**
- Строить **денормализованные витрины (Data Marts)**, ориентированные на конкретные темы: продажи, финансы и т.п.
- Использовать **многомерное моделирование** — схемы "звезда" и "снежинка"
- Обеспечивать согласованность данных через **конформные измерения (conformed dimensions)**

## 🟦 Особенности

| Признак                  | Описание                                                       |
|--------------------------|----------------------------------------------------------------|
| **Подход**               | Сначала Data Marts, затем интеграция                           |
| **Модель хранения**      | Денормализованная (звезда или снежинка)                        |
| **Время до результата**  | Быстрое — можно запускать витрины по одной                     |
| **Фокус**                | На бизнес-пользователях и аналитике                            |
| **Простота BI**          | Упрощённая модель — легко использовать в отчётности            |

---

## ✅ Преимущества

- Быстрый старт с реальными результатами
- Проще для понимания и поддержки
- Удобна для аналитиков и BI-систем
- Легко масштабируется по тематикам

---

## ❌ Недостатки

- Может быть сложно интегрировать в единый [[EDW]]
- Требует внимательного управления **conformed dimensions**
- Возможна избыточность данных

---

## 📊 Kimball vs Inmon

| Признак            | Kimball                                     | Inmon                                      |
|-------------------|---------------------------------------------|--------------------------------------------|
| Подход            | Сначала Data Marts                          | Сначала EDW                                |
| Модель хранения    | Денормализация (звезда/снежинка)           | Нормализация (3NF)                         |
| Время до результата | Быстро                                     | Долго                                      |
| Бизнес-ориентированность | Высокая                               | Средняя                                    |
| Интеграция данных  | Позже, через conformed dimensions          | На этапе EDW
