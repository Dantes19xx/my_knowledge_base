## 📘 Что такое Apache Spark

**Apache Spark** — это **распределённая платформа обработки данных**, предназначенная для **быстрой** и **масштабируемой** обработки больших объёмов данных в памяти (in-memory).

Разработан как **ускоренная альтернатива Hadoop MapReduce**, с поддержкой стриминга, машинного обучения и SQL.

---

## 🔥 Основные особенности

| Характеристика        | Описание                                                                 |
|------------------------|--------------------------------------------------------------------------|
| **In-memory обработка**| Обработка данных в оперативной памяти — быстрее, чем в Hadoop           |
| **Поддержка разных API**| Scala, Python (PySpark), Java, SQL, R                                  |
| **Модульность**        | Ядро + модули Spark SQL, MLlib, GraphX, Spark Streaming                 |
| **Расширяемость**      | Поддерживает кластеры: YARN, Kubernetes, Mesos, Standalone              |

---

## 🧮 Основные абстракции

| Абстракция  | Описание                                              |
|-------------|-------------------------------------------------------|
| **RDD**     | Resilient Distributed Dataset — устойчивая коллекция данных |
| **DataFrame** | Табличное представление (как в SQL / Pandas)       |
| **Dataset** | Типизированные структуры (в Scala и Java)            |

---

## 🧰 Основные модули

| Модуль            | Назначение                                      |
|-------------------|-------------------------------------------------|
| **Spark SQL**     | Работа с данными через SQL, DataFrame API       |
| **Spark Streaming** | Обработка потоков в реальном времени           |
| **MLlib**         | Библиотека машинного обучения                   |
| **GraphX**        | Обработка графов и сетей                        |
| **Structured Streaming** | Упрощённая стриминг-обработка через DataFrame API |

---

## 🆚 Spark vs Hadoop MapReduce

| Признак                | Apache Spark             | Hadoop MapReduce        |
|------------------------|--------------------------|--------------------------|
| Обработка              | In-memory (RAM)          | На диске (HDFS)         |
| Скорость               | Быстро                   | Медленно                |
| API                    | Высокоуровневые          | Низкоуровневые          |
| Повторное использование данных | Да (через кэширование) | Нет                    |
| Поддержка стриминга    | Да                       | Ограниченная            |

---

## ✅ Преимущества

- Быстрая in-memory обработка
- Унифицированная платформа: batch + streaming + ML + SQL
- Поддержка масштабирования до тысяч узлов
- Гибкие API и высокая производительность

---

## ❌ Недостатки

- Требовательность к памяти и ресурсам
- Крутая кривая обучения (особенно RDD)
- Менее эффективен на небольших объёмах данных

---

## 📎 Где используется

- [[Data lake]]/ETL пайплайны
- Машинное обучение на больших данных
- Real-time обработка логов, событий
- Построение аналитических витрин
