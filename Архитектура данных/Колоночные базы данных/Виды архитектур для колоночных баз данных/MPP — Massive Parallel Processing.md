# MPP (Massive Parallel Processing) в колоночных БД

## 📘 Что такое MPP

**MPP (Massively Parallel Processing)** — это архитектурный подход к обработке данных, при котором задача распределяется **между множеством узлов**, каждый из которых работает **независимо** и **параллельно**.

Этот подход особенно эффективен в **аналитических нагрузках**, часто применяется в **колоночных БД** и хранилищах данных.

---

## 🔍 Как работает

- Данные **разбиваются** и **распределяются** по множеству **узлов/нодов**
- Каждый узел содержит **часть данных** и собственный CPU, память, диск
- Запрос выполняется **параллельно на всех узлах**
- Результаты **агрегируются** на координаторе (dispatcher node / head node)

---

## 📊 Преимущества MPP в колоночных БД

| Преимущество           | Описание                                                             |
|------------------------|----------------------------------------------------------------------|
| **Масштабируемость**   | Можно линейно добавлять узлы и масштабировать хранилище              |
| **Производительность** | Параллельное выполнение запросов ускоряет аналитику                 |
| **Оптимизация под чтение** | Колоночные БД идеальны для аналитических запросов                 |
| **Сжатие данных**      | Колоночные форматы (Parquet, ORC) позволяют экономить хранилище     |

---

## ❌ Ограничения

- Высокая стоимость инфраструктуры
- Сложность настройки и поддержки
- Не предназначены для OLTP-нагрузок (вставки, обновления, удаление в реальном времени)

---

## 💾 Примеры MPP СУБД

| Система             | Особенности                                     |
|---------------------|-------------------------------------------------|
| **Amazon Redshift** | MPP + колоночное хранение, облачное             |
| **Google BigQuery** | Serverless MPP, работает поверх Dremel          |
| **Snowflake**       | Разделение compute/storage, авто-MPP            |
| **Greenplum**       | Open-source, PostgreSQL-based, MPP              |
| **ClickHouse**      | Колоночная СУБД, поддерживает кластеризацию     |
| **Vertica**         | Колоночная, оптимизирована под аналитику        |
| **Azure Synapse**   | MPP-архитектура с глубоким облачным интегрированием |

---

## 🧭 Когда применять

- Обработка **больших объёмов аналитических данных** (Big Data)
- Построение **Data Warehouse** и **Data Lakehouse**
- **Сложные аналитические запросы** и отчёты
- **Временные окна**, агрегации, фильтрации по колонкам
