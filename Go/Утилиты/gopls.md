# gopls — язык-сервер для Go

## Что такое `gopls`

`gopls` — это утилита командной строки, реализующая **Language Server Protocol (LSP)** для языка программирования **Go**.

Он предоставляет поддержку интеллектуальных функций в редакторах кода, таких как:

- автодополнение,
- переход к определению,
- документация по наведению,
- переименование символов,
- импорт недостающих пакетов,
- подсветка ошибок и др.

> `gopls` разрабатывается официальной командой Go. Он заменяет устаревшие инструменты: `gocode`, `guru`, `goimports` и др.

---

## Тип: Утилита (CLI)

- **Не библиотека.**
- **Не подключается в код.**
- **Запускается редактором в фоне.**

---

## Возможности

| Функция                  | Описание |
|--------------------------|----------|
| Автодополнение           | Предлагает имена функций, переменных и пр. |
| Переход к определению    | Быстрый переход к объявлению символа |
| Переименование           | Безопасное переименование символа во всем проекте |
| Подсказки по типам       | Показывает типы выражений и переменных |
| Документация             | Показывает GoDoc/комментарии |
| Импорт пакетов           | Автоматически добавляет нужные импорты |
| Анализ кода              | Показывает ошибки и предупреждения |
| Форматирование           | Форматирует код согласно `gofmt` |

---

## Установка

```bash
go install golang.org/x/tools/gopls@latest
```
