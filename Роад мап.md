# Карьерный роадмап: путь к техлиду в международной компании

## 1. Текущая позиция
- Middle Python Developer
- Работа над одним SaaS-продуктом (ТОО)
- Основные задачи: багфиксы, поддержка, знание бизнес-процессов
- Автономность в принятии решений
- Стек: Python, Flask, jQuery, SQL (базовый уровень)
- Достижения: сертификация Python, рост зарплаты, участие в код-ревью

## 2. Цели (горизонт 2–5 лет)
- Роль: опытный разработчик или техлид
- Компания: международная или авторитетная
- Зарплата: $3000+
- Ценности: знания, статус, тех. влияние, сильная команда
- Проекты: исключение финтеха и медицины
- Формат: удалёнка или офис — без разницы

---

## 3. План развития (роадмап)

### 3.1 Прокачка навыков

#### 3.1.1 Укрепление фундамента (1–4 месяца)
- [ ] Углубить Python:
  - генераторы, декораторы, менеджеры контекста
  - `typing`, `dataclasses`, `collections`
- [ ] Flask / FastAPI:
  - структура приложения, blueprints, middlewares
  - переход на FastAPI (постепенно)
- [ ] SQL:
  - оконные функции, индексация, explain plan
- [ ] Тестирование:
  - pytest, fixtures, mocks, coverage, TDD
- [ ] Git:
  - rebase, cherry-pick, conflict resolution

#### 3.1.2 Архитектура и системное мышление (3–9 месяцев)
- [ ] Пройти курс Яндекса по архитектуре
- [ ] Изучить паттерны проектирования (GoF, GRASP)
- [ ] Освоить CI/CD:
  - GitHub Actions или GitLab CI
  - Docker, Docker Compose
- [ ] Изучить:
  - 12 фактор-приложений
  - SOLID-принципы
  - Clean Architecture

#### 3.1.3 Английский язык
- [ ] 10–15 минут в день:
  - общение (AI, партнёры)
  - написание текстов на IT-темы
  - интервью и подкасты
- [ ] Темы: IT-интервью, архитектура, работа в команде

#### 3.1.4 Pet-проект для портфолио (начать через 1–2 месяца)
- [ ] Тематика: любой сложный backend (не финтех, не медицина)
- [ ] Использовать:
  - архитектуру (например, DDD или MVC)
  - тестирование
  - CI/CD, Docker
  - документацию (README, Swagger/OpenAPI)
- [ ] Выложить на GitHub

---

## 3.2 Переход в международную компанию

#### 3.2.1 Подготовка к интервью
- [ ] Алгоритмы и структуры данных (1–2 месяца)
  - пройти курс или книги (например, Grokking algorithms)
  - LeetCode: 3–5 задач в неделю
- [ ] Подготовка резюме:
  - акцент на навыках, бизнес-результатах, проектах
- [ ] Mock-интервью:
  - с AI или людьми
  - технические + поведенческие вопросы
- [ ] LinkedIn и профиль на GitHub:
  - проекты, активность, краткое описание целей

#### 3.2.2 Каналы поиска
- [ ] LinkedIn + англоязычные CV
- [ ] StackOverflow Jobs, Relocate.me, WeWorkRemotely
- [ ] Тестовые задания и процессы собеседований

---

## 3.3 Личный бренд (по желанию, но полезно)

- [ ] Писать короткие заметки в Telegram, Хабр, LinkedIn (1–2 раза в месяц)
- [ ] Темы: архитектура, Python, опыт работы, уроки и грабли
- [ ] Присутствие на GitHub: коммиты, проекты, активность
