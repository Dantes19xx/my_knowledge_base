
## 📋 Основные подходы

|Подход|Описание|Примеры|
|---|---|---|
|**В памяти (in-memory)**|Быстрое хранение во время работы приложения|Кеш, временные флаги|
|**Файлы**|Сохранение сериализованных данных|`settings.json`, `pickle`|
|**Базы данных**|Долговременное хранение|Настройки, корзины, истории|
|**Клиентское хранилище**|LocalStorage, SessionStorage, cookies|Токены, UI-настройки|
|**State-менеджеры**|Redux, MobX, Zustand|SPA-приложения|
|**URL (query/hash)**|Состояние передаётся в адресной строке|Фильтры, вкладки|
|**State Restoration**|Восстановление после закрытия|Мобильные приложения|
|**Hooks и context API**|`useState`, `useReducer`, `useContext`|React-компоненты|

---

### 🗂️ По типу хранения

#### 🔹 Временное состояние

- В памяти (RAM)
    
- В течение одной сессии
    
- Используется для UI, модалок, временных значений
    

#### 🔹 Постоянное состояние

- Хранится между перезапусками
    
- Файлы, БД, localStorage
    
- Примеры: настройки пользователя, JWT, кеш
    

---

### 🔐 Особенности

|Механизм|Применение|
|---|---|
|JWT/session cookies|Авторизация|
|IndexedDB|Оффлайн-возможности браузера|
|URL-параметры|Переходы, шэринг состояния|
|Stateless API|Каждое обращение — без сохранения состояния сервера|

---

### 💻 Примеры

#### Flask-приложение:

- `session`: cookies / [[Redis]]
    
- JWT для логина
    
- `request` для временного состояния
    

#### React-приложение:

- `useState` — локально
    
- `Redux` / `Zustand` — глобально
    
- `localStorage` — долговременное
