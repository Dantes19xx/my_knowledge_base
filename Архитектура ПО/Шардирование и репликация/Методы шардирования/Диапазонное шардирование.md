
## 📌 Определение
**Диапазонное [[Шардирование|шардирование]]** — это метод распределения данных по шардам на основе упорядоченных диапазонов значений шард-ключа. Каждому шару назначается конкретный диапазон значений, и записи направляются в соответствующий шард в зависимости от значения ключа.

---

## ⚙️ Механизм работы

1. Определяется поле, по которому будет происходить шардирование (например, `user_id` или `created_at`).
2. Все возможные значения этого поля разбиваются на **непересекающиеся диапазоны**.
3. Каждому диапазону сопоставляется один из шардов.
4. При вставке/запросе система проверяет, в какой диапазон попадает значение, и направляет операцию в нужный шард.

---

## 🗂️ Пример

Допустим, у нас есть 3 шарда с такими диапазонами:

- `shard0`: `user_id` от 0 до 9999  
- `shard1`: `user_id` от 10000 до 19999  
- `shard2`: `user_id` от 20000 до 29999  

Запись с `user_id = 15892` попадёт в `shard1`.

---

## ✅ Преимущества

- 🔍 **Поддержка диапазонных запросов** — идеально для `BETWEEN`, `>`, `<`, `ORDER BY`.
- 📅 Эффективен для временных данных (`created_at`, `timestamp`).
- 📦 Простой и понятный механизм — легко отлаживать и визуализировать.

---

## ❌ Недостатки

- 🔥 **Горячие шарды** — данные могут скапливаться в одном диапазоне (например, при автонумерации).
- 🛠️ **Неравномерное распределение** — требует анализа распределения данных.
- ⚙️ **Сложнее масштабировать** — добавление нового шарда требует переноса диапазонов.

---

## 🧠 Когда использовать

- Когда важны **диапазонные запросы** и сортировка по ключу (например, по времени или ID).
- Когда значения ключей **имеют предсказуемый, возрастающий характер**.
- При построении **таймсерийных хранилищ**, логов, финансовых операций по времени.

---

## 📎 Примечание
В MongoDB диапазонное шардирование настраивается по ключу без `hashed`:

```json
{ "created_at": 1 }
```

## 🔚 Вывод

Диапазонное шардирование отлично подходит для приложений с упорядоченными данными и диапазонными запросами. Однако требует внимательного подхода к проектированию, чтобы избежать дисбаланса и горячих шардов.
