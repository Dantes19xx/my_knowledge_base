# 🧭 USE, RED, Четыре золотых сигнала

Эти подходы помогают систематически выбирать метрики, которые стоит отслеживать в продакшене.

---

 🔧 [[USE]] (Utilization, Saturation, Errors)

 🛑 [[RED]] (Rate, Errors, Duration)

 🌟 Четыре золотых сигнала (The [[Four Golden Signals]])

---

## 🧱 Сравнительная таблица подходов

| Подход        | Назначение                | На чём фокусируется                    | Где применим                 |
| ------------- | ------------------------- | -------------------------------------- | ---------------------------- |
| **USE**       | Низкоуровневый анализ     | Утилизация, перегрузка, ошибки         | Хосты, железо, сети          |
| **RED**       | Производительность API    | RPS, ошибки, латентность               | HTTP/[[gRPC]] сервисы        |
| **4 сигнала** | Общий мониторинг сервисов | Латентность, ошибки, трафик, насыщение | Любые распределённые системы |

---

## 🧩 Комбинация подходов

Для полного охвата часто комбинируют:
- **RED** → для микросервисов
- **USE** → для серверов и инфраструктуры
- **4 сигнала** → в качестве базового фреймворка
