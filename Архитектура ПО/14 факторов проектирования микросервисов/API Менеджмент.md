## Определение

API Менеджмент — это управление жизненным циклом и взаимодействием API между микросервисами и внешними потребителями: контроль доступа, версиями, мониторинг, безопасность и документация.

---

## Основные цели

- Обеспечить **стандартизированное взаимодействие** между сервисами
- Управлять **безопасностью** и **доступом** к API
- Обеспечить **обратную совместимость** и **версионирование**
- Повысить **наблюдаемость** API
- Упростить поддержку и **документирование**

---

## Основные функции

### 1. [[API Gateway]]

API-шлюз как единая точка входа:

- Авторизация и аутентификация
- Rate limiting и quota management
- Роутинг запросов к сервисам
- TLS-терминация
- Сбор метрик и логов

**Примеры:** Kong, Tyk, Apigee, Amazon API Gateway, NGINX, Istio Gateway

---

### 2. Версионирование API

- **URL-based:** `/api/v1/resource`
- **Header-based:** `Accept: application/vnd.service.v2+json`
- **Query-param:** `/resource?version=1.2`

**Рекомендация:** не нарушать контракты старых версий, предоставляя backward-compatible API

---

### 3. Документирование

- Автоматическая генерация: Swagger/OpenAPI
- Хостинг и просмотр: Swagger UI, Redoc
- Соглашения по описанию полей, ошибок и примеров

---

### 4. [[Безопасность]] API

- Аутентификация: OAuth2, JWT
- Авторизация: ACL, RBAC, ABAC
- Rate limiting, throttling
- CORS и защита от атак (например, replay, injection)

---

### 5. Мониторинг и аналитика

- Сбор статистики по использованию
- Выявление «горячих» точек
- Аномалии в доступе
- Интеграция с observability-стеком ([[Prometheus]], [[Grafana]], Loki)

---

### 6. Управление SLA и throttling

- Ограничения по кол-ву запросов в минуту/час/день
- Ограничения по типам пользователей (платные/бесплатные)
- Отказоустойчивость API ([[Timeout|таймауты]], [[Fallback]], [[Retry]])

---

## Роли в экосистеме

| Участник        | Ответственность                                |
|------------------|------------------------------------------------|
| Продюсер API     | Создаёт и публикует API                        |
| Потребитель API  | Использует API для интеграции                  |
| API Gateway      | Роутинг, безопасность, политика доступа        |
| API Менеджер     | Управляет жизненным циклом, версионированием   |

## Вывод

API — это контракт между сервисами и внешними системами. Грамотный API-менеджмент обеспечивает **безопасное, предсказуемое и управляемое взаимодействие** между компонентами и позволяет масштабировать архитектуру без потери контроля.
