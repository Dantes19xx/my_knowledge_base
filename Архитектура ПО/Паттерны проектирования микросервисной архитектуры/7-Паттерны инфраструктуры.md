## Сетевые инфраструктурные паттерны

Service Discovery, Service Mesh и Service Registry относятся к инфраструктурным паттернам (иногда их выделяют в отдельную подкатегорию — сетевые инфраструктурные паттерны), так как они обеспечивают коммуникацию, маршрутизацию и обнаружение сервисов в распределённой системе.

---


### 1. Service Discovery

| Характеристика         | Описание |
|------------------------|----------|
| Назначение             | Автоматическое обнаружение сервисов в распределённой системе. |
| Пример                 | `frontend` находит экземпляры сервиса `order-service` через механизмы Discovery. |
| Инструменты            | Consul, Eureka, Zookeeper, Kubernetes DNS |
| Плюсы                  | Масштабируемость, упрощение конфигурации сервисов, автоматизация. |
| Минусы                 | Необходимость синхронизации состояний сервисов, возможные задержки при поиске. |

---

### 2. Service Registry

| Характеристика         | Описание |
|------------------------|----------|
| Назначение             | Хранилище метаданных о доступных сервисах (их адресах, портах, версиях). |
| Пример                 | Consul, Eureka, Zookeeper. |
| Принцип работы         | Сервисы регистрируются в реестре при старте и обновляют своё состояние по мере изменений. |
| Плюсы                  | Централизованное управление, упрощает динамическую маршрутизацию и балансировку нагрузки. |
| Минусы                 | Задержки на обновление состояния, возможные проблемы с консистентностью. |

---

### 3. Service Mesh

| Характеристика         | Описание |
|------------------------|----------|
| Назначение             | Управление коммуникациями между сервисами (маршрутизация, безопасность, мониторинг). |
| Пример                 | Istio, Linkerd, Consul Connect |
| Принцип работы         | Внедрение sidecar-прокси для каждого сервиса, который занимается маршрутизацией, балансировкой нагрузки, метриками, безопасностью. |
| Плюсы                  | Централизованное управление трафиком, улучшенная безопасность, мониторинг и трассировка. |
| Минусы                 | Дополнительная сложность настройки, возможная нагрузка на сеть. |
