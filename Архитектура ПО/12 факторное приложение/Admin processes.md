## Admin processes — Административные процессы

**Принцип:**  
Одноразовые административные задачи (миграции БД, отладочные команды) должны выполняться в том же окружении, что и основное приложение, и быть доступными через интерфейс командной строки.

---

### Основные положения

| Аспект      | Описание                                                                             |
| ----------- | ------------------------------------------------------------------------------------ |
| Назначение  | Гарантировать совместимость и предсказуемость выполнения админ-команд.               |
| Практика    | Вынести команды в CLI-интерфейс, запускать их через тот же код и окружение.          |
| Инструменты | `manage.py` (Django), `flask CLI`, [[Alembic]], `invoke`, `make`, `docker exec`.     |
| Антипаттерн | Отдельный скрипт вне проекта, запускаемый вручную и использующий другие зависимости. |

---

### Примеры

**Flask CLI:**
```python
@app.cli.command("create-user")
def create_user():
    username = input("Enter username: ")
    # Логика создания пользователя
```
