## Concurrency — Параллелизм

**Принцип:**  
Приложение должно масштабироваться за счёт запуска множества процессов, каждый из которых выполняет одну чётко определённую задачу. Это следует UNIX-философии: *"делай одну вещь и делай её хорошо."*

---

### Основные положения

| Аспект      | Описание                                                                                  |
| ----------- | ----------------------------------------------------------------------------------------- |
| Назначение  | Масштабирование приложения через множественные процессы или потоки.                       |
| Практика    | Разделение функциональности на типы процессов: веб-процессы, воркеры и т.д.               |
| Инструменты | Использовать процесс-менеджеры: `gunicorn`, `celery`, `supervisord`, [[Kubernetes]] Pods. |
| Антипаттерн | Монолитный процесс, выполняющий все задачи (HTTP, фоновую обработку, планирование).       |

---

### Примеры

**Gunicorn (Python WSGI):**
```bash
gunicorn app:app --workers=4
```
