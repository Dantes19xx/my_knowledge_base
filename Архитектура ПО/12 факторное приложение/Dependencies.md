Приложение должно явно заявлять о всех своих зависимостях, используя систему управления зависимостями, чтобы приложение было легко развертываемо и его зависимости были четко определены.

Все зависимости должны быть явно задекларированы, не использовать глобальные библиотеки.

|Инструмент|Назначение|Пример|
|---|---|---|
|`requirements.txt`|Указание зависимостей|`Flask==2.2.5`|
|`venv`/`virtualenv`|Изоляция окружения|`python -m venv venv`|
|Установка|Повторяемость сборки|`pip install -r requirements.txt`|

**Явное декларирование зависимостей**:
1. **Явное декларирование зависимостей**: 
	Все внешние библиотеки и компоненты, которые приложение использует, должны быть явно указаны. В Python это обычно делается через файл requirements.txt или систему управления зависимостями pipenv или poetry.
2. **Изоляция зависимостей**: Необходимо изолировать все зависимости от глобальных изменений. Обычно это делает с помощью venv.
3. **Не полагаться на установленные на системе библиотеки**: Вместо использования глобально установленных библиотек (например, через `pip install`), важно использовать локальные зависимости, которые легко воспроизвести на других системах или окружениях. Это помогает гарантировать, что приложение будет работать одинаково, независимо от среды.
4. **Решения для контейнеризации**: Если приложение контейнеризируется (например, с использованием [[Docker]]), все зависимости должны быть указаны в Dockerfile. Это также гарантирует, что приложение будет развернуто с теми же зависимостями, что и на локальной машине разработчика
*`dockerfile`*
*`FROM python:3.9`*
*`WORKDIR /app`*
*`COPY requirements.txt .`*
*`RUN pip install -r requirements.txt`*

#### Почему это важно?

- **Гарантированная совместимость**: Заявление о зависимостях помогает убедиться, что приложение будет работать одинаково на всех машинах и в разных средах.
    
- **Упрощение развертывания**: Явное указание зависимостей упрощает процесс настройки приложения и его развертывания.
    
- **Минимизация ошибок**: Приложение будет работать так, как ожидается, без неожиданных ошибок из-за несовместимых версий библиотек.
