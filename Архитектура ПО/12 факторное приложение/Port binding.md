## Port binding — Привязка к порту

**Принцип:**  
Приложение должно само обслуживать HTTP-запросы, привязываясь к определённому порту, а не полагаться на внешний веб-сервер (например, Apache или Nginx).

---

### Основные положения

| Аспект         | Описание                                                                 |
|----------------|--------------------------------------------------------------------------|
| Назначение     | Делает приложение самостоятельным сервисом, готовым к контейнеризации и деплою в облако. |
| Практика       | Привязывать приложение к порту и слушать входящие соединения самостоятельно. |
| Переменные     | Использовать `PORT` из переменных окружения для гибкости. |
| Антипаттерн    | Приложение работает только под управлением внешнего веб-сервера. |

---

### Примеры

**Python (Flask):**
```python
import os
from flask import Flask

app = Flask(__name__)

port = int(os.environ.get("PORT", 5000))
app.run(host="0.0.0.0", port=port)
```
JS:
```JavaScript
const express = require('express');
const app = express();

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => console.log(`Server listening on port ${PORT}`));
```

  

**Примечание**:

Принцип “Port binding” особенно важен для облачных сред (Heroku, [[Kubernetes]]), где инфраструктура ожидает, что приложение будет слушать определённый порт.\
