
## Disposability — Одноразовость

**Принцип:**  
Процессы приложения должны быть быстро запускаемыми и корректно завершаться. Это упрощает масштабирование, деплой и устойчивость системы.

---

### Основные положения

| Аспект         | Описание                                                                 |
|----------------|--------------------------------------------------------------------------|
| Назначение     | Повышение надёжности и гибкости за счёт быстрого старта и завершения процессов. |
| Практика       | Быстрый запуск, ловля сигналов завершения (SIGTERM), очистка ресурсов.  |
| Инструменты    | Использование graceful shutdown, хендлеров сигналов, автоматическая перезапуск через оркестраторы (K8s, systemd). |
| Антипаттерн    | Долгий старт, зависание при завершении, потеря данных при остановке.     |

---

### Примеры

**Обработка SIGTERM в Python:**
```python
import signal
import sys

def graceful_exit(signum, frame):
    print("Shutting down gracefully...")
    # Закрытие соединений, сохранение состояния и т.д.
    sys.exit(0)

signal.signal(signal.SIGTERM, graceful_exit)
```
